# План релиза версий TrustLang и назначение и примерный набор фич

## Текущая рабочая ветка 0.6.x

## Версия 0.9.x

Цель версии: Сборка компилятора с помощью TrustLang

- Переписать исходный код компилятора на TrustLang как демонстарция способности работать со сложным кодом.
- Доказательное (контрактное) программирование для кода компилятора

## Версия 0.8.x - 

Цель версии: LLVM бэкенд, аудит и оптимизация.

- Бакэенд LLVM для непосредственой генерации кода без преобразования в С++
- Реализация лексера и парсера в виде шаблонов (при компилировании trust) и доступ к Term с помощью Reflection
- Аудит, анализ и оптимизация по итогам обратной связи
- Полная реализация стандартной С++ библиотеки

## Версия 0.7.x - гененрации кода

Цель версии: Полноценная реализация всех возможностей языка и генерация модульного кода

- Полноценная релиазация для ООП, лябд, шаблоно, ссылочные типы данных и захват ссылок
- бэкенд для clang (как so) семантический ABI и загрузка модулей, стандатрная ббилиотека (заготовки)
- системыне фукнции (TypeId по имени типа, регистрация новго типа в конкретной группе TypeRegistre (с помощтю атрубута???)
- Тензоры на LibTorch и многомерные массивы лдитералы, отрицатльеные индексы и диапазоны
- Форматные строки с именованными аргументами, with формы `&`/`&?`/`&&` + `__timeout__` и межпоточная синхронизаци
- Операторы типизации `~`/`~~`/`~~~`
- перегрузка операторов и фунций (внутритиповые перегрузки сигнатур).
- Генерация С++ кода с учтом модульности исходников и управлене манглингом имен генерируемых функций через флаг компилятора
- Кросплатформенная генерация кода С++ под Microsoft (или иные версии компиляторов и стандартов)
- Реализация полноценного анализа кода при работе с памятью в том числе для безопасной многопоточности (thread async) 
и при работе со ссылками (trusted-cpp) на основе автоматической расстановка атрубутов для фукнций.
- Анализ кода для безопасной многопоточности (thread async) на основе атрубутов
- Анализатор с графом зависимостей имен и типов. Вывод минимально возможности типа. Определение "горячего пути" для переменных с выведенными типами данных. 
Генерация прототипов функция в том числе с перегрузкой для использования на "горячем пути". Генерация разнородных сборных типов переменных для индивидуального использования для каждого "горячего пути" 
вместо единого универсально TypedValue. Генерация тел (или шаблонов) для функций на "горячем пути".


## Версия 0.6.x (РАБОЧАЯ)

Цель версии: Проработка лексики и архитектуры компилятора и домонстрация работы на простых примерах.
Пишем простой код на С++ (как нативные имана) с дополнительными возможностями и проврками TrustLang

+ Синтаксис и прототипы для ООП, лябд, шаблонов, ссылочные типы данных и захват ссылок
+ исполняемый файл как один исходник (модули потом)
+ посимвольный доступ к строкам

- Стабилизация лексики языка
- Создание рабочего прототипа с ограниченными возможностями для тестирования лексики и общей архитектуры проекта.
- Создание средств разработки (компилятор, LSP сервер, плагин для vscode, песочница для примеров)
- Документирование синтаксиса и архитекутрых решений

Отдельные задачи на память:
- полная (end-to-end) реализация PoW-защиты на /run и /download для песочницы или встаивание капчи при необходимости
