# План релиза версий TrustLang и назначение и примерный набор фич

## Текущая рабочая ветка 0.6.x

## Версия 1.x - первый продакшен

Реализованы все запаланированные фичи проект готов к осторожному исопльзвоанию в продакшене.

## Версия 0.9.x - предпродакшен и фидбек

- Полные аудит кода проекта и согласованности архитекутры
- Готовность к исопльзованию в экспериментальных преоктах и обработка обратной связи

## Версия 0.8.x - анализ и оптимизация

- Полная реализация оставшихся тяжелых типов и стандартной С++ библиотеки
- Реализация полноценного анализа кода при работе с памятью
- Анализ кода для безопасной многопоточности

## Версия 0.7.x - гененрации кода

- Уточненеи синтаксиса по итогам обратной связи
- Полноценная релиазация ООП, исключений и других конструкций языка
- Начальная реализация тензоров на LibTorch
- Генерация С++ кода с учтом модульности исходников
- Доработка логики гененрации кода с поддержкой всех возможностей С++
- Анализатор с графом зависимостей имен и типов. Вывод минимально возможности типа. Определение "горячего пути" для переменных с выведенными типами данных. Генерация прототипов функция в том числе с перегрузкой для использования на "горячем пути". Генерация разнородных сборных типов переменных для индивидуального использования для каждого "горячего пути" вместо единого универсально TypedValue. Генерация тел (или шаблонов) для функций на "горячем пути".

## Версия 0.6.x (РАБОЧАЯ) - лексика и архитектура

- Стабилизация лексики языка
- Создание рабочего прототипа с ограниченными возможностями для тестирования лексики и общей архитектуры проекта.
- Создание средств разработки (компилятор, LSP сервер, плагин для vscode, песочница для примеров)
- Документирование синтаксиса и архитекутрых решений

Отдельные задачи на память:
- полная (end-to-end) реализация PoW-защиты на /run и /download для песочницы или встаивание капчи при необходимости


## Версия 0.5.0 (ВЫПУЩЕНА) - стартовая версия после переименования

Переименование проекта NewLang в TrustLang и рефакторинг кода под исолпьзование ИИ агентов.
