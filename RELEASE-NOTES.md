# TrustLang v0.6.0 — Release Notes

**Первый рабочий релиз.** TrustLang — высокоуровневый язык программирования общего назначения
с безопасным управлением памятью, реализованный как транспилятор в C++.

Релиз включает компилятор-транспилятор (`trust`), рантайм, инструменты разработчика
(`trust-lsp`, `trust-dap`, VS Code-расширение) и дистрибутив-архив. На текущем этапе
компилируются и запускаются отдельные текстовые примеры.

---

## Реализованный функционал

### Ядро языка (транспилятор → C++)

- **Транспиляция в C++ и сборка** через сгенерированный Makefile: исполняемые файлы,
  объектные (`-c`), статические (`-a`) и динамические (`-l`) библиотеки.
- **Лексический и синтаксический анализ** на базе Flex/Bison; грамматика без shift/reduce-конфликтов.
- **Макропроцессор и DSL-макросы**: `@if`, `@elif`, `@else`, `@while`, `@dowhile`, `@loop`,
  `@match`/`@case`/`@default`, `@return`, `@break`/`@continue`, `@assert`, `@verify`, `print(...)`
  и др.
- **Переменные и функции**: объявление с типом и с автоматическим выводом типа; авто-расширение
  выведенных типов в составной арифметике (например, `Bool → Int64`).
- **Управляющие конструкции**: условный оператор, циклы `while` (в т.ч. с `else`),
  `match`/`case`, `break`/`continue`, именованные блоки-метки (`label { ... }`), оператор `return`.
- **Интеграция с C++**: вставки нативного кода `{% ... %}`; использование trust-переменных
  внутри вставок (`$name`/`@name` → C++-идентификаторы); нативный импорт C/C++ функций
  через `%name` (прямой вызов без FFI).
- **Пространства имён**: глобальная `::`, именованная `ns::`, анонимная `_` (внутренняя компоновка).
- **Модули**: оператор `\module(...)` с glob-масками импорта, компиляция модулей в отдельные
  единицы компиляции, экспорт-интерфейс модуля, сборка модулей `.trust`.
- **Рациональные числа произвольной точности** (GMP): литерал `num\den` и тип `Rational`
  с неявным приведением к строке.
- **Системная функция `print(fmt, args...)`**: форматный вывод в стиле `std::format`
  в `trust::outs()`.
- **Динамическая типизация**: переменные с невыводимым статически типом хранятся в `std::any`;
  операции над `any`-операндами безопасно оборачиваются в `std::any_cast<CommonType>`.
- **Проверка диапазона при сужении**: явный каст `:Type(expr)` транслируется в
  `trust::checked_cast<Type>` с рантайм-проверкой.
- **Проверки `assert`/`verify` включены по умолчанию** (отключаются флагом `-Wno-assert`).
- **Точка входа `@main():={...}`**: компиляция самодостаточного исполняемого файла.

### Инструменты разработчика

- **Source map (trust ↔ C++)**: встроенный маппинг позиций в ELF-секции `.debug_trust_map`.
- **LSP-сервер (`trust-lsp`)**: переход к определению, hover, inlay hints, document links,
  инкрементальная синхронизация.
- **DAP-сервер (`trust-dap`)**: отладка через GDB/MI с трансляцией позиций trust ↔ C++
  (прототип).
- **VS Code-расширение**: подсветка синтаксиса и интеграция с LSP.
- **Solver (SMT-LIB 2)** с опциональной интеграцией Z3 (прототип).

### Рантайм (`trust-runtime`)

- Сборка как динамической (`trust-runtime.so`), так и статической (`trust-runtime.a`) библиотеки.
- Публичные рантайм-заголовки (`trust/rational.hpp`, `trust/io.hpp`, `trust/assert.hpp`,
  `trust/checked_cast.hpp`) встроены в рантайм-библиотеку и извлекаются конвейером при необходимости.
- Режимы линковки рантайма: `--link-runtime static|shared` (по умолчанию `static`).

### Дистрибутив

- Цель `package`: дистрибутив-архив `trust-lang-<version>-<hash>-<os>-<arch>.tar.gz`
  и `.vsix` (VS Code-расширение), помещаемые в `_build/dist/`.
- Архив содержит `trust`, `trust-lsp`, `trust-dap`, `trust-runtime.{a,so}`, `VERSION`/`LICENSE`
  и `manifest.txt` с метаданными сборки.
- Сборка под Windows — через WSL2 (POSIX/ELF-тулчейн).

## Что пока НЕ сделано

Следующие возможности концепции языка находятся в стадии прототипа или запланированы
и в текущий релиз не входят:

- [ ] ООП: классы, наследование, «утиная типизация».
- [ ] Итераторы и циклы по коллекциям.
- [ ] Многозадачность (вытесняющая/кооперативная, async).
- [ ] Полноценные тензорные вычисления (опциональная сборка `WITH_TORCH`).
- [ ] Формальная верификация (Trust Checking / SMT + Z3) — реализован только прототип.
- [ ] REPL-режим интерпретатора.
- [ ] Нативный Windows (без WSL2).
- [ ] Полноценная стандартная библиотека (именованные/необязательные параметры, генерация
  документации и прочие возможности — в проработке).

## Установка и запуск

```sh
# сборка дистрибутива
cmake -B _build && cmake --build _build --target package

# распаковка и запуск примера
tar -xzf _build/dist/trust-lang-<version>-<hash>-linux-x86_64.tar.gz
trust -q -o hello hello.src && ./hello
```

CLI: `--emit-cpp/--emit-ast/--emit-tokens` (отладка), `-c/-a/-l/-m` (объект/статические/
динамические/модуль), `--link-runtime static|shared`, `--no-dsl/--dsl <file>`.

> Windows: сборка рекомендуется через **WSL2** (POSIX/ELF-тулчейн). Нативная сборка — отдельная
> задача.

## Тестирование

Тесты зарегистрированы в **CTest**:

```sh
cmake -B _build && cmake --build _build
ctest --test-dir _build --output-on-failure
```

- **unit/** — C++ unit-тесты (GTest), единый исполняемый файл `unit_tests`.
- **lit/** — LIT-интеграционные тесты (CLI `trust` + FileCheck).
- **vscode/** — тесты VS Code-расширения (`vscode_unit`, `vscode_dap`, `vscode_lsp`).

`make run_tests` собирает тестовые бинарники и запускает тот же CTest-набор.

Полный перечень изменений — в [CHANGELOG.md](CHANGELOG.md). Подробное описание идеи и
особенностей языка — в [ARTICLE.md](ARTICLE.md).
