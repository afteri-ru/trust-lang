# README.md

Негативная фикстура `internal_memory_guard`. Проверяемые случаи:

- `include/demo/small/` — один файл, MEMORY.md отсутствует: по правилу «малая реализация
  (≤3 файлов и ≤16 KiB)» это допустимо, нарушения нет.
- `include/demo/big/` — четыре файла реализации и нет MEMORY.md: обязательный файл памяти
  отсутствует, гейт обязан выдать нарушение.
- `include/demo/terse/` — MEMORY.md есть, но меньше нижнего порога полезности 1000 байт:
  гейт обязан выдать нарушение с требованием перенести знания в WHY-комментарии кода/README.md.

Корневой `include/demo/MEMORY.md` корректен и содержит ссылки на все три зоны, поэтому
единственные срабатывания гейта — два ожидаемых нарушения в `big/` и `terse/`.
