# Types - Система типов

## Назначение

Закрытая система типов языка TrustLang: идентификаторы типов (TypeId), метаданные (TypeMeta), runtime-значения (Value), реестр типов (Registry) и иерархия типов (примитивные, структуры, классы, тензоры, кортежи, variant).

## Особенности реализации

- **Закрытая система** - любой пользовательский тип наследуется от существующего; функция без явных типов - неявный шаблон.
- **TypeId / TypeMeta** - уникальные идентификаторы типов с метаданными (размер, выравнивание, kind).
- **Registry** - глобальный реестр типов для runtime-диспетчеризации (boxing/unboxing, dynamic_cast). Имена типов хранятся владеющими `std::string`-ключами (без висячих `string_view`); `TypeDescriptor::name` тоже владеющая копия, поэтому `getFullTypeName()` для пользовательских алиасов возвращает точное имя (не мусор). `reset()` на каждый запуск семантики сбрасывает пользовательские/структурные типы до builtin-состояния. Структурные типы с пустым именем (функциональные сигнатуры) не регистрируются в name-индексе. `isUserDefinedType()` различает пользовательские алиасы и встроенные (Integer/String/Char…) по `registry_index` (встроенные регистрируются первыми, `index ≤ m_builtinCount`).
- **Value** - type-erased runtime-значение с поддержкой примитивных типов, структур, классов, тензоров (libtorch) и type-safe variant.
- **Подтипы (SubType)** - типы с суженным диапазоном значений для статического доказательства корректности (без runtime-накладок).
