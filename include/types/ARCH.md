# Реализация системы типов

## Идентификатор типа

Каждый тип имеет уникальный идентификатор, который кодирует категорию, группу, индекс и мета-информацию. Это позволяет проверять принадлежность типа к категории или группе за O(1) без обращения к lookup-таблицам.

`type_id_t` (uint32_t) — идентификатор типа. Кодирует все признаки в битовых полях.
`type_t` (uint64_t) — пара идентификаторов: (primary, secondary). Для пользовательских типов secondary хранит ID базового встроенного типа.

## Класс жизненного цикла (TypeClass)

Каждый тип относится к одному из четырёх классов, определяющих способ его создания, копирования и уничтожения:

- **Trivial** — нет конструктора/деструктора/виртуальных функций. Допускает memcpy. (int, float, bool, указатели)
- **Relocatable** — есть конструктор и деструктор, нет виртуальных. Допускает relocation (memcpy + destroy старого). (std::string, std::vector, Rational)
- **Complex** — полноценный конструктор/деструктор/move. Не допускает memcpy. (Tensor, Closure, Coroutine)
- **Polymorphic** — есть виртуальная таблица. Требует dynamic_cast. (Class, Interface)

### Модификаторы

- **IsRef** — признак ссылки/указателя. Тип `Int32*` — это модифицированный Int32, а не отдельный тип. Везде, кроме codegen, ведёт себя как базовый тип.
- **IsSigned** — для целых типов: signed/unsigned. Влияет на выбор инструкций (IDIV vs DIV, SAR vs SHR).
- **IsUD** — пользовательский тип (субтип). Наследует от встроенного и хранит его идентификатор.
- **IsTmpl** — compile-time шаблон (Vector, Map). Не участвует в runtime-типизации.

### Поле Data

Поле Data имеет переменную семантику в зависимости от категории:

- **AliasID** — для конкретных типов: номер алиаса (0 = конкретный тип, 1–511 = альтернативное имя).
- **Значение enum** — для enum: хранится прямо в TypeId без выделения памяти.
- **Первичный код** — для пользовательских типов: позволяет частично идентифицировать тип без registry.
- **Число параметров шаблона** — для шаблонов.

## Категории и группы

| Категория | Назначение | Группы |
|-----------|-----------|--------|
| Void | Нет значения | Default |
| Logical | Троичная логика | Default (Bool) |
| Integers | Целые signed числа | Ix (8/16/32/64) |
| Unsigned | Целые unsigned числа | Ix (8/16/32/64) |
| Numbers | Числа с плавающей точкой | Fx (16/32/64) |
| BFloat | Brain Float 16 | Default |
| Complex | Комплексные числа | Cx (32/64) |
| Rationals | Рациональные числа | Default |
| Strings | Строки | Char (UTF-8), Wide (wchar_t) |
| Tensors | Многомерные массивы | Dense, Sparse |
| Containers | Контейнеры | List, Dict, Set |
| Structured | Структурированные типы | Struct, Enum, Union, Variant, Optional |
| Callable | Вызываемые объекты | Executable, Closurable, Suspendable |
| Classes | ООП классы | Default |
| Pointers | Варианты ссылок | Raw, Shared, Unique, Weak |
| Ranges | Диапазоны | Default |
| Iterators | Итераторы | Forward, Bidirectional, RandomAccess |
| DateTime | Время | Duration, TimePoint |
| Exceptions | Исключения | Default |

## Пара идентификаторов (Type)

Для пользовательских типов (субтипов) используется 64-битная пара: идентификатор самого типа и идентификатор его базового встроенного типа. Это позволяет проверять иерархию (например, «является ли целым числом?») без обращения к registry, что критично для динамической типизации в runtime.

## Категория и группа (type_class_t)

Вспомогательная структура `type_class_t` объединяет Category и Group в одно значение для групповых операций (например, bulk-добавление заголовков для всех типов одной группы).

## Predicates

- `is_alias()` — тип является алиасом (AliasID != 0)
- `is_user_defined()` — пользовательский тип
- `is_arithmetic_cat(Category)` — Integers | Numbers | Complex | Rationals | Unsigned | BFloat
- `is_trivially_copyable_cat(Category)` — Integers | Numbers | Strings | Unsigned | BFloat | Bool
