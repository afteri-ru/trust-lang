## Architecture

Стандартная библиотека — СУЩНОСТИ на существующих механизмах языка: исходники на самом TrustLang (`.src`)
и C++-заголовки библиотечных типов. Вся библиотека доставляется ЕДИНЫМ пакетом `share/trust/stdlib.trust`
(собирается компилятором по `trust.toml`, `[[layout.layers]]`; третий слой — заголовки из
`include/runtime/trust`). Пакет распаковывается в `<build>/stdlib`; `build.conf` добавляет
`-Istdlib -Istdlib/include`. Порядок prelude: `dsl.src` → `iterator.src` → `async.src` → главный модуль.

## Facts and invariants

- **Stdlib — НЕ категория типов:** здесь реализации предобъявленных встроенных типов
  (`stdlib/builtin/*.src`, загружаются по требованию) и обычные объявления. Реализация использует `=`
  и НЕ создаёт новый тип (`::=` создаёт новый); критерии встроенности — `types`.
- **⚠ Префиксы НЕ смешиваются:** `@trust/…` — встроенные типы, `@stdlib/…` — стандартная библиотека;
  оба разрешаются из распакованного `stdlib.trust` через `-Istdlib/include`. `@` в метаданных —
  признак «эмитировать quoted include из пакета», а не механизм извлечения.
- `iterator.src` участвует ТОЛЬКО в семантике (в кодоген не входит); `--no-stdlib` отключает и его.
  LSP публикует prelude как `<cppt-каталог>/stdlib/dsl.src`.
- **Итераторы:** единственный Trust-тип `Iterator<T>` ↔ единственная C++-реализация
  `trust::Iterator<T>` (type-erased курсор); `Generator<T>` — корутинный источник, не итератор.
- **⚠ `Generator<T>` (корутины) — только `<coroutine>`:** `std::generator` отсутствует у GCC 13
  (дефолтный `c++` генерируемых программ).
- **Async-слой (`trust::async`) — стандартный C++:** типы доступны без импорта, но `#include` и
  `-pthread` добавляются ON-USE по `[[link.headers]]` (`stdlib/async/thread_pool.hpp`).
- **⚠ `@[borrowed]` на КЛАССЕ наследуется производными типами** (`Iterator<T>`, `Box<Int32>`) —
  помечать методы НЕ нужно.
- **Заменяемые реализации встроенных типов:** `stdlib/builtin/rational_openssl.src` по умолчанию НЕ
  загружается и переопределяет default только при явной загрузке/копировании в проект.
- `:Tensor` — Core-тип: предобъявлен в `types`, реализация — провайдер `tensor.trust`.

## Decisions

- Раскладку архива описывает сам манифест `trust.toml`; система сборки передаёт только каталог пакета
  и путь архива.

## Relations

- Встроенные типы, рантайм-заголовки, критерий встроенности — `runtime`, `types`.
- Общий механизм пакетов — `package`; C++20-модуль компилятора — `trust`.
