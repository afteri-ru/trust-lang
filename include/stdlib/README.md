# Stdlib — Мульти-версионный анализ API стандартной библиотеки C++

Утилита выполняет синтаксический анализ C++ исходного файла с помощью Clang и извлекает информацию об API стандартной библиотеки (методы, функции, типы) для последующего сравнения между версиями стандартов C++.

## Архитектура

Проект состоит из четырёх основных компонентов:

### MethodAnalyzer

Анализатор методов и функций. Извлекает структурированную информацию из Clang AST:
- Квалифицированное имя (`std::vector::push_back`)
- Тип возвращаемого значения
- Типы параметров
- Нормализованную сигнатуру для сравнения
- Категорию объявления (function, method, class template, function template, type alias)
- Флаги: `const`, `static`, `template`

### ApiComparator

Хранит и сравнивает API между версиями стандартов:
- Сопоставляет Qualified Name с паттернами поиска
- Проверяет обратную совместимость (все методы базовой версии должны присутствовать)
- Группирует данные по паттернам и версиям

### AstMatchHandler

Callback для Clang AST MatchFinder:
- Регистрирует матчеры для различных типов объявлений
- Делегирует анализ в MethodAnalyzer
- Фильтрует результаты по паттернам через ApiComparator

### OutputFormatter

Форматирует и записывает результаты:
- Группировка методов по классам
- Отображение базовой версии
- Отображение новых методов по версиям
- Отображение изменённых сигнатур

## Сборка

Проект использует CMake. Для сборки требуется:

- Clang (>= 15) с установленными заголовочными файлами для разработки (libclang-dev)
- CMake (>= 3.16)

```bash
mkdir build && cd build
cmake ..
make stdlib
```

После сборки будет автоматически запущен AST-анализ, результаты появятся в `build/stdlib/`.

## Использование

```
stdlib <output-dir>
```

- `<output-dir>` — каталог для записи результатов (будет создан при необходимости)

Файл для анализа задаётся при компиляции через `SOURCE_FILE_PATH` (по умолчанию `src/stdlib/trust_stdlib.cpp`).

## Принцип работы

1. Утилита запускает Clang Tooling для анализа файла.
2. Анализ выполняется последовательно для версий C++: CPP11, CPP17, CPP20, CPP23.
3. Для каждой версии собираются все объявления из системных заголовков.
4. MethodAnalyzer извлекает структурированную информацию из каждого объявления.
5. ApiComparator сопоставляет имена с паттернами и проверяет совместимость.
6. OutputFormatter записывает результаты в файлы.

## Формат выходных файлов

Файлы именуются по паттернам: `std_map.matches.txt`, `std_vector.matches.txt`.

Структура файла:
```
# Base: c++11

class std::map
  find: iterator find(const key_type& x)
  insert: std::pair<iterator,bool> insert(const value_type& x)
  begin: iterator begin() const
  begin: iterator begin()  # c++17

--- c++17 new ---
+ emplace: std::pair<iterator,bool> emplace(Args&&...)
```

## Паттерны поиска

Паттерны задаются в `api_comparator.cpp`:
- `std::*map` → `std_map`
- `std::vector` → `std_vector`

Сопоставление использует glob-алгоритм с поддержкой `*` и `?`.

## Обработка ошибок

Если в анализируемом файле обнаружены синтаксические ошибки, утилита прерывает анализ.
Если метод из базовой версии отсутствует в более новой — анализ прерывается с сообщением об ошибке.
