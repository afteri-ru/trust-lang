# Stdlib — Мульти-версионный анализ API стандартной библиотеки C++

Утилита выполняет синтаксический анализ C++ исходного файла с помощью Clang и извлекает информацию об API стандартной библиотеки (методы, функции, типы) для последующего сравнения между версиями стандартов C++.

## Архитектура

Проект состоит из четырёх основных компонентов:

### MethodAnalyzer

Анализатор методов и функций. Извлекает структурированную информацию из Clang AST: квалифицированное имя, тип возвращаемого значения, типы параметров, нормализованную сигнатуру, категорию объявления (function, method, class template, function template, type alias), флаги `const`, `static`, `template`.

### ApiComparator

Хранит и сравнивает API между версиями стандартов. Сопоставляет Qualified Name с паттернами поиска, проверяет совместимость (все методы базовой версии должны присутствовать), группирует данные по паттернам и версиям.

### AstMatchHandler

Callback для Clang AST MatchFinder. Регистрирует матчеры для различных типов объявлений, делегирует анализ в MethodAnalyzer, фильтрует результаты по паттернам через ApiComparator.

### OutputFormatter

Форматирует и записывает результаты: группировка методов по классам, отображение базовой версии, новых методов по версиям, изменённых сигнатур.

## Сборка

Требуется Clang (>= 15) с libclang-dev и CMake (>= 3.16). После сборки автоматически запускается AST-анализ.

## Использование

```
stdlib <output-dir>
```

Файл для анализа задаётся при компиляции через `SOURCE_FILE_PATH`.

## Принцип работы

1. Запуск Clang Tooling для анализа файла.
2. Последовательный анализ для версий C++: CPP11, CPP17, CPP20, CPP23.
3. Сбор всех объявлений из системных заголовков для каждой версии.
4. Извлечение структурированной информации через MethodAnalyzer.
5. Сопоставление имён с паттернами и проверка совместимости через ApiComparator.
6. Запись результатов через OutputFormatter.

## Паттерны поиска

Паттерны задаются в `api_comparator.cpp`. Используют glob-алгоритм с поддержкой `*` и `?`.

## Обработка ошибок

При синтаксических ошибках в анализируемом файле анализ прерывается. Если метод из базовой версии отсутствует в более новой — анализ прерывается с сообщением об ошибке.
