## Architecture

Модульные юниты кодогенерации (`module/module_emit.cpp`): публикация заголовка модуля, out-of-line
определения, umbrella-заголовки фасадов. Полный контракт заголовка модуля и связь с `pipeline`
(`lowerModuleUnit`, `HeaderArtifact`) — `pipeline/MEMORY.md`.

## Facts and invariants

- **Сайт импорта — `#include`, не forward-decl:** C++-объявления клиента публикует заголовок модуля;
  экспорт-набор нужен только для имя-зависимых фактов (native-import, stack-check). Сопоставление с
  AST-узлами заголовка — по `node->origin` (fallback — сам узел), TermPtr-сопоставления нет.
- **⚠ Экспорт-набор заголовка — только VarDecl/FuncDecl/TypeDecl:** отбор делает `pipeline`
  (`backend/emit.cpp`); иной kind в `emitImportScope` — `faultUnexpectedKind` (объявление в заголовке
  обязано быть эмитировано; тихий пропуск молча ломал бы заголовок).
- **⚠ Заголовок публикуемого типа отдаёт только ПРОТОТИП;** определение печатает `.cppt` как out-of-line
  (`Owner::name`, default-аргументы не повторяются). В заголовке тело остаётся ТОЛЬКО когда его нельзя
  вынести: член шаблонного record, шаблонный метод, `@[constexpr]` (`methodBodyMustBeInHeader`). Если
  такое тело ссылается на `__::`-символ, это Trust-диагностика (anonymous namespace `.cppt` невыразим
  в `.hppt`).
- **⚠ Инстанциация шаблона уникальна по построению (R21/R40):** определение шаблона/члена шаблонного
  record эмитится в ЗАГОЛОВОК модуля (см. `methodBodyMustBeInHeader`), т.е. как C++-шаблон; при
  использовании одной специализации из нескольких TU C++ ODR-сливает её — дублей определений нет.
  В `.cppt` инстанциации не выносятся. Явных инстанциаций/специализаций в языке нет
  (`TemplateSpecializationKind::kExplicitSpecialization` — резерв, не выставляется).
- **Три прохода заголовка:** forward-декларации генерируемых классов → определения типов → прочее.
  Forward нужен, когда сигнатура члена ссылается на тип ниже в том же заголовке (`StrChar::toWide` →
  `StrWide`); эмитится только для реализаций builtin с генерируемым классом; C++-имя forward'а выводится
  тем же кодеком, что и у определения (единый путь вывода C++-имени).
- **Заголовок фасада (реэкспорт) — umbrella:** `#pragma once` + `#include` заголовков
  реэкспортируемых модулей, собственных объявлений не содержит.
- **⚠ Интерфейс эмитится один раз — в заголовке модуля:** `.cppt` использует его через `#include`
  (`selfHeaderInclude`) и не повторяет текст.
- **⚠ Диапазон объявления мапит только заголовок:** признак — `forwardDeclOnly` (эмиссия заголовка) либо
  отсутствие `selfHeaderInclude` (юнит без своего заголовка). Иначе запись стека создаётся без range-mapping
  (`mapStart(..., recordRange=false)`): остаются name-mapping идентификаторов и диапазоны тел (R40).
