## Architecture

Разделяемый компонент «модель модулей и пакетов», общий для менеджера пакетов (trust-pm) и
компилятора. Описывает модуль как единицу исходного текста и пакет как его композицию;
обеспечивает размещение, чтение, упаковку/распаковку и контроль целостности. Не содержит
языковой нотации импорта, монтирований, оркестрации загрузки, криптографии и транспорта.

Файлы: `module_path.hpp` (семантический путь), `source_tree.hpp` (`SourceTree`/`DirectoryTree`/
`ArchiveTree`), `package.hpp` (границы, вложенные пакеты), `locate.hpp` (размещение),
`archive.hpp` (`.trust` pack/unpack/list/read), `errors.hpp` (`PackageError`/`PackageException`).

- **Модуль** — единица исходного текста.
- **Пакет** — композиция модулей и/или вложенных пакетов; граница отмечается манифестом;
  вложенный пакет — отдельная адресуемая композиция.
- **Идентичность модуля семантическая** (может совпадать с физическим путём, но не
  обязана); физическое хранение произвольно (переименование/распаковка допустимы).
- **Размещение**: поиск модуля внутри дерева пакета по его пути; нормализация/сопоставление.
- **Чтение/запись**: перечисление и чтение модулей по пути; упаковка/распаковка пакета.
- **Контроль целостности — хеш** (`packArchive()` возвращает sha256; сама функция — `utils`).

## Facts and invariants

- Модуль — единица; пакет — композиция; границы выводятся из расположения манифестов,
  содержимое вручную не перечисляется.
- Вложенные пакеты не сплющиваются — сохраняют собственную адресуемость.
- `name` из манифеста — метаданные поставки; на семантику адресации модулей не влияет.
- Один модуль — одна семантическая идентичность; неоднозначность — ошибка (без тихого выбора).
- Маркер границы `kManifestFileName` определён ЗДЕСЬ (единственный источник); `pm` его
  переиспользует через `using packages::kManifestFileName`.
- Ошибки — СВОИ `PackageError{code,message}`/`PackageException` (для контракта trust↔trust-pm);
  ядро не печатает, вызывающий маппит (pm → `PmError`/JSON-конверт).
- Компонент — лист: без `nlohmann_json`, без `diag`/`Context`; зависимость только `utils` (FileIO, sha256).
- Целостность = хеш (компонент); подлинность = подпись (вне компонента, trust-pm).
- Бинарный интерфейс (C++ ABI) и ABI-упаковка (ELF/SABI) — вне компонента.

## Decisions

- Компонент разделяемый: компилятор использует модель для поиска/чтения модулей, PM —
  для упаковки/распаковки/проверки.
- Языковая адресация (`\`, `\\`, `\\\`) и монтирования остаются в компиляторе; здесь их нет.
- Криптография не входит (только хеш).

## Relations

- `pm` (trust-pm) — зависимости, подпись/крипто, транспорт, lock; потребитель `packages`
  (pack/unpack/list/read; маркер `kManifestFileName`).
- `module_loader` (компилятор) — оркестрация загрузки; назначенный потребитель `packages`.
- `syntax` — парсер; обращается к слою разрешения компилятора (не напрямую к `packages`).
- `module_sabi` — бинарный интерфейс, вне.
