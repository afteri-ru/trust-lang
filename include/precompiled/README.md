# Precompiled - Предварительно откомпилированные заголовки

## Назначение

Ускорение сборки проекта за счёт предварительной компиляции тяжелых заголовков (libtorch), используемых в runtime.

## Особенности реализации

- **PCH-файл** - `torch_pch.hpp` включает стабильные заголовки libtorch, редко изменяющиеся в процессе разработки.
- **Интеграция с CMake** - PCH подключается на уровне таргета для ускорения инкрементальной сборки runtime-компонентов.
- **Минимальный состав** - только те заголовки, которые действительно замедляют сборку; остальные подключаются напрямую.

## Общий PCH проекта (`trust_pch`)

- **Назначение** - предкомпилировать стабильный общий префикс проекта (STL + `ast_nodes.hpp`,
  `registry.hpp`, `symbol_table.hpp`, `strings.hpp`) и ускорить фронтенд каждого TU.
- **Опция** - `TRUST_USE_PCH` (default `ON` в dev, `OFF` в release). Release с `ON` - ошибка
  конфигурации: артефакт обязан собираться только из явных include.
- **Не несущая конструкция** - каждый TU обязан собираться и с `-DTRUST_USE_PCH=OFF`; это
  обязательный верификационный конфиг (PCH иначе маскирует отсутствующий `#include`).
- **Не включает `trust/version.h`** (git-хеш в dev) - иначе PCH инвалидировался бы на каждый коммит.
- Актуальность обеспечивается depfile (`-MD -MF`): изменение любого включённого заголовка
  пересобирает PCH и всех потребителей.
