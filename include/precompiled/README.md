# Precompiled — Предварительно откомпилированные заголовки

## Назначение

Ускорение сборки проекта за счёт предварительной компиляции тяжелых заголовков (libtorch), используемых в runtime.

## Особенности реализации

- **PCH-файл** — `torch_pch.hpp` включает стабильные заголовки libtorch, редко изменяющиеся в процессе разработки.
- **Интеграция с CMake** — PCH подключается на уровне таргета для ускорения инкрементальной сборки runtime-компонентов.
- **Минимальный состав** — только те заголовки, которые действительно замедляют сборку; остальные подключаются напрямую.
