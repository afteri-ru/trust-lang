# Trust - инфраструктура C++20-модуля компилятора

## Назначение

Инфраструктура сборки самого компилятора: C++20-модуль `trust` (прекомпилированный модуль
`trust.pcm` и объект `trust_module.o` собираются здесь) и генерируемый заголовок версии
`version.h`. Собственной библиотечной цели нет — манифест объявлен для единообразия проверок
(`public_api_guard`).

## Границы

- Рантайм-заголовки ВСТРОЕННЫХ типов — в `include/runtime/trust/` (в частности, общий ABI-заголовок
  `type_state.hpp` с `TypeId`/`QualType`).
- Исходники и заголовки СТАНДАРТНОЙ БИБЛИОТЕКИ — в `include/stdlib/`.

## Особенности реализации

- Компилятор подключает общий ABI-заголовок как `runtime/trust/type_state.hpp` (через
  `-I${PROJECT_INCLUDE_DIR}`); `TRUST_COMPILE_OPTIONS` НЕ добавляет `-I…/runtime`, поэтому прочие
  переопределяемые runtime-заголовки компилятору не видны.
- Модуль привязывается к цели функцией `target_trust_module(target)`.
