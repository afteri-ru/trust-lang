# Location - примитивы позиций и идентификаторов файлов

## Назначение

Header-only низкоуровневые примитивы позиций и идентификаторов файлов/модулей, общие для `diag` и всех,
кто оперирует файлами и диапазонами. Зависит только от `utils`; нижестоящих компонентов нет.

## Особенности

- **Тег пространства позиций:** `Mapper*` (builder-space, offset относительно body выходного файла) vs
  `Reader*` (reader-space, offset относительно полного содержимого = prepend+body). Битовая раскладка
  идентична, поэтому неявное смешение запрещено тегом на уровне компилятора.
- **`ModuleIndex`** — strong-type идентичности модуля; `{0}` — валидный главный модуль, «модуля нет»
  выражается только `invalid()`/`isValid()`.
- **`module_name.hpp`** — единственная формула C++-имени модуля (encoder + `ModuleNameLookup`); повторять
  формулу в других компонентах запрещено. Имя модуля в C++-символ не входит (ABI прозрачен).
- Значения — POD, передаются по значению, не владеют ничем. Инварианты — `MEMORY.md`.
