# Package - пакеты Trust (`.trust`)

## Назначение

`.trust` — gzip-tar архив исходников с манифестом `trust.toml` в корне; единый способ доставки кода и
заголовков (stdlib, provider-пакеты, пользовательские). Компонент отвечает за модель/парсинг манифеста,
целостность и упаковку/распаковку. Публичный API — `package/manifest.hpp`, `package/package.hpp`.

## Особенности

- **Пакет всегда ОДИН:** вложенных импортируемых пакетов нет; `name` — идентичность, граф плоский. Версия —
  semver пакета (не компилятора); версия toolchain — `[build].toolchain`.
- **Целостность обязательна:** `[files]` хранит MD5 каждого файла (кроме `trust.toml`); отсутствие/лишний
  файл, несовпадение хеша — ошибка `verifyPackage`, не пропуск проверки.
- **`[[artifact]]` — контракт линковки;** линковка demand-driven (`@[link]` или `[[link.headers]]`).
- **Воспроизводимость:** `createTarGz` детерминирован (`--sort=name --mtime=@0`), иначе md5 архива меняется
  и ломает ccache.
- Общие tar-примитивы — внутренний `archive/archive_io.hpp`. Инварианты — `MEMORY.md`.
