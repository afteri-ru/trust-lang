## Architecture

`trust-lsp` — LSP-сервер: `TrustLsp` — чистый диспетчер методов, маршрутизирует на stateless-сервисы;
in-process транспиляция через `Context` + `Pipeline::run`; транспорт stdin/stdout и TCP. Помимо LSP есть
playground-режимы `--json` (live-контракт) и `--html`/`--html-full`. Детали — `lsp/README.md`,
`NAVIGATION.md`, `HTML.md`; реализация — internal-подкаталоги `services/`, `catalog/`.

## Facts and invariants

- **⚠ Завершение не показывает невидимые имена (per-site):** фильтр — `isSymbolVisible`:
  свой модуль видит всё, чужой — экспорт из маски сайта либо реэкспорт владельца через фасад.
  Позиционный фильтр (строки объявления vs курсор) применяется ТОЛЬКО к объявлениям текущего файла:
  диапазоны импортированных модулей принадлежат другим файлам. Private/import-hidden типы
  предлагаются только для СОБСТВЕННОГО модуля; квалифицированные имена фильтруются по `namespacePath`.
- **⚠ Символы — из `SemanticModel::symbols()`:** имя ХРАНИТСЯ С сигналом (`$`/`%`/`@`/`:`),
  `namespacePath` — без сигналов; сопоставление под курсором — `completion::stripSigil`.
  Индекс собирается ОДИН раз в фазе семантики (идемпотентная регистрация не даёт дублей).
- **⚠ Видимость и поисковые области — в `SemanticModel` (`CachedSource::model`):** сайты импорта,
  реэкспорт фасадов, `using`-скоупы, namespace-алиасы, module-алиасы, ссылки. Единственный парсер
  масок — загрузчик; сайты уже отфильтрованы по `importer == mainModuleIndex`.
- **⚠ Completion алиасов:** `\m::` — через module-алиасы (вставка сохраняет набранный spelling);
  `\facade::outer::ns::` — longest-prefix по экспортируемым алиасам фасада; локальные namespace-алиасы
  предлагаются как namespace-кандидаты.
- **⚠ Переход/hover по ССЫЛКЕ — из `SemanticModel::references()`:** диапазон ссылки расширяется до конца
  qualified-токена (AST-диапазон модульной ссылки может покрывать только префикс); относительное имя
  разрешается от `projectDir`, а не от CWD.
- **⚠ Документация в hover:** под курсором ссылка — док РАЗРЕШЁННОГО объявления; иначе видимые
  одноимённые кандидаты + предупреждение о неоднозначности; макросы — `isMacroVisible` +
  `BuiltinCatalog::macroDoc`.
- **⚠ Макросы: видимость per-module, не per-site:** `nullopt` = прелюдия/stdlib DSL (виден везде),
  значение = модуль определения. `isSymbolVisible` к макросам НЕ применяется (они не экспортируются).
- **⚠ Тексты символов — view в пул строк компиляции:** `SemanticModel` держит пул (`shared_ptr`),
  `CachedSource` держит `Context`, поэтому `name`/`documentation` валидны между запросами.
- **⚠ TypeId резолвится ТОЛЬКО в реестре своего файла:** пользовательские типы пер-файловые, их индексы
  могут численно совпадать у разных документов; TypeId символа в другую `CachedSource` не передаётся.
- **Единые источники имён:** имена кода — `SemanticModel::symbols()`; встроенные — глобальный
  `BuiltinCatalog`
  (строится ОДИН раз, не копируется). Доки макросов — `Context::macroDocs()`; прагма-макросы НЕ входят в
  `m_predef_macro` (иначе ломается PragmaCheck).
- **⚠ Опции применяются ПО ИСТОЧНИКУ** (`applyAnalysisArgsBySource`, приоритет `opts_.shebangMode`):
  ошибка из шебанга — диагностика на строке шебанга, из окружения — в лог. Общие опции LSP не
  объявляет. Ловушка `argv[0]` — как в `driver`.
- **Диагностики:** публикуются только ТЕКУЩЕГО trust-файла; исключение анализатора на частичном AST —
  `internal analysis error`, символы дособираются.
- **Шебанг для `trust`** — комментарий лексера (опции через argv ОС); LSP открывает файл как текст и
  извлекает опции сам.
