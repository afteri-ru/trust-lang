## Architecture

`trust-lsp` — LSP-сервер: `TrustLsp` — чистый диспетчер методов на stateless-сервисы; in-process
транспиляция через `Context` + `Pipeline::run`; транспорт stdin/stdout и TCP. Помимо LSP — playground-режимы
`--json` и `--html`/`--html-full`. Детали — `lsp/README.md`, `NAVIGATION.md`, `HTML.md`; реализация —
`app/` (точка входа `trust-lsp`), `emit/` (HTML/playground-эмиссия и её ассеты), `protocol/` (LSP-сообщения),
`services/`, `catalog/`.

## Facts and invariants

- **⚠ Завершение не показывает невидимые имена (per-site):** фильтр — `isSymbolVisible`: свой модуль видит
  всё, чужой — экспорт из маски сайта либо реэкспорт через фасад. Позиционный фильтр — только к объявлениям
  текущего файла. Private/import-hidden типы — только для СОБСТВЕННОГО модуля; квалифицированные имена — по
  `namespacePath`.
- **⚠ Символы — из `SemanticModel::symbols()`:** имя ХРАНИТСЯ С сигналом (`$`/`%`/`@`/`:`), `namespacePath` — без;
  сопоставление под курсором — `completion::stripSigil`. Индекс собирается один раз в фазе семантики.
- **⚠ Видимость и поисковые области — в `SemanticModel` (`CachedSource::model`):** сайты импорта, реэкспорт
  фасадов, `using`, namespace-алиасы, ссылки. Единственный парсер масок — загрузчик; сайты уже
  отфильтрованы по `importer == mainModuleIndex`.
- **⚠ Completion алиасов:** локальные namespace-алиасы (`a :- ns::;`) — namespace-кандидаты
  (longest-prefix по привязкам активного скоупа).
- **⚠ Переход/hover по ССЫЛКЕ — из `SemanticModel::references()`:** диапазон ссылки расширяется до конца
  qualified-токена (AST-диапазон модульной ссылки может покрывать только префикс); относительное имя — от
  `projectDir`, не от CWD.
- **⚠ Документация в hover:** под ссылкой — док РАЗРЕШЁННОГО объявления; иначе видимые одноимённые кандидаты +
  предупреждение; макросы — `isMacroVisible` + `Context::macroDoc` (док прогона).
- **⚠ Макросы: видимость per-module, не per-site:** `nullopt` = stdlib DSL (везде), значение = модуль
  определения. `isSymbolVisible` к макросам НЕ применяется.
- **⚠ Тексты символов — view в пул строк компиляции:** `SemanticModel` держит пул, `CachedSource` — `Context`,
  поэтому `name`/`documentation` валидны между запросами.
- **⚠ TypeId резолвится ТОЛЬКО в реестре своего файла:** пользовательские типы пер-файловые, индексы могут
  численно совпадать у разных документов; TypeId в другую `CachedSource` не передаётся.
- **⚠ Кэши документа — сервисное состояние LSP, не факты §4:** `CachedSource` (`sourceCache_`, исходник+`Context`+
  `SemanticModel`) и `cppToTrustCache_` (обратный маппинг `.cppt`→`.src`) принадлежат `DocumentManager`;
  инвалидация — ре-анализ документа (`didChange`/`didOpen`) и очистка при старте. Компонент `lsp` вне целевой
  модели (`ARCHITECTURE.md` §6) — эти кэши не являются фактами компилятора и строк §4 не требуют (в отличие от
  пула текстов прогона — он принадлежит `session`/`Context`).
- **Единые источники имён:** код — `SemanticModel::symbols()`; встроенные — глобальный `BuiltinCatalog`
  (строится один раз; каталог хранит ТОЛЬКО имена). Доки макросов — у владельца прогона
  (`Context` файла, включая прагма-override); прагма-макросы НЕ в `m_predef_macro` (иначе
  ломается PragmaCheck).
- **⚠ Опции применяются ПО ИСТОЧНИКУ** (`applyAnalysisArgsBySource`, приоритет `opts_.shebangMode`): ошибка из
  шебанга — на строке шебанга, из окружения — в лог. Ловушка `argv[0]` — как в `driver`.
- **Диагностики публикуются по URI ФАЙЛА ЗАПИСИ (единый механизм):** каждая запись уходит в URI своего
  файла (кросс-файловый Note цепочки не теряется); записи без локации и не-навигируемые источники
  (output, in-memory `@`) пропускаются; запрошенный файл публикуется ПОСЛЕДНИМ (наблюдаемый контракт).
  Повторный анализ гасит пустым массивом URI своего документа, куда он ранее публиковал, но больше
  не публикует; URI с кросс-файловыми диагностиками принадлежит последнему опубликовавшему документу
  (`uriOwners_`) — чужой документ их не гасит.
  Исключение анализатора на частичном AST — `internal analysis error`, символы дособираются.
- **Шебанг для `trust`** — комментарий лексера (опции через argv ОС); LSP открывает файл как текст и извлекает
  опции сам.
