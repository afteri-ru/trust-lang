# Система типов TrustLang (для парсера)

TrustLang имеет закрытую систему типов. Любой новый тип данных, который создается пользователем, обязательно должен быть наследником одного из уже существующих. Это позволяет использовать обобщённое программирование и шаблоны для любых типов данных и применять одновременно строгую типизацию во время компиляции и динамическую типизацию во время выполнения.

Система типов построена по иерархическому принципу с трёхуровневой структурой: **Категория → Группа → Конкретный тип**.

- **Категория** — самое общее семейство типов (Arithmetics, Strings, Containers, Callable и т.д.)
- **Группа** — детализация внутри категории (Integers, Unsigned, Numbers, Functions, Closures и т.д.)
- **Конкретный тип** — конкретный тип данных (Int8, Int64, Float64, StrChar и т.д.)

Тип может иметь алиас — альтернативное имя для существующего типа. Один тип может иметь несколько алиасов.
Группы и категории могут иметь несолько иерархий соотвествующим разным критериям.

Корень всех типов — `:Any`, который соответствует значению любого типа. Кроме этого есть два служебных типа/значения:

- `:Void` — собственный тип и одновременно значение, которое обозначает отсутствие типа.
- `:None` — не инициализированное значение любого типа, кроме `:Void`.

## Иерархия типов

```
:Any
 ├─ :Logical        →  :Bool
 │
 ├─ :Arithmetics
 │   ├─ :Integers   →  :Int64  → :Int32 → :Int16  →  :Int8
 │   │                                              (:Char)
 │   ├─ :Unsigned   →  :UInt64 → :UInt32  →  :UInt16 →  :UInt8
 │   │                (:DDWord)   (:DWord)   (:Word)   (:Byte) 
 │   ├─ :Numbers      →  :Float64 →  :Float32 →  :Float16
 │   │                   (:Double)   (:Single)
 │   ├─ :BFloat     →  BFloat16
 │   ├─ :Complex    →  :Complex32 (:Float16+:Float16)
 │   │                →  :Complex64 (:Float32+:Float32)
 │   └─ :Rationals   →  :Rational
 │
 ├─ :Strings
 │   ├─ :StrChar      (:FmtChar — printf-формат)
 │   └─ :StrWide      (:FmtWide — printf-формат)
 │
 ├─ :Tensors        →  Dense  →  Sparse
 │
 ├─ :Containers
 │   ├─ Vector
 │   ├─ List
 │   ├─ Map
 │   └─ ...
 │
 ├─ :Structured
 │   ├─ Struct (POD без vtable)
 │   ├─ Enum
 │   ├─ Variant
 │   ├─ Tuple
 │   └─ Optional
 │
 ├─ :Classes
 │   ├─ Class           — с vtable, виртуальные методы
 │   └─ Interface       — только методы, без данных
 │
 ├─ :Callables
 │   ├─:Function        — указатель на код
 │   ├─ :Closure         — function pointer + capture
 │   ├─ :Coroutine       — closure + state machine
 │   ├─ :Generator       — coroutine с co_yield
 │   ├─ :Method          — метод класса
 │   └─ :Delegate        — указатель на метод
 │
 ├─ :Pointers (IsRef) *
 │   ├─ :Raw             — голый указатель (FFI)
 │   ├─ :Shared          — shared_ptr семантика
 │   ├─ :Unique          — unique_ptr семантика
 │   └─ :Weak            — weak_ptr (предотвращение циклов)
 │
 ├─ :Ranges
 │   ├─ :Range
 │   ├─ :Slice
 │   └─ :View
 │
 ├─ :Iterators
 │   ├─ :Forward
 │   ├─ :Bidirectional
 │   ├─ :RandomAccess
 │   └─ ...
 │
 ├─ :DateTime
 │   ├─ :UnixTime
 │   ├─ :Duration
 │   └─ :TimePoint
 │
 └─ :Exceptions
     ├─ :Exception
     └─ :Error
```

---

**\***) - **:Pointer (IsRef)** — это **модификатор** для любого типа. Каждый тип может использоваться как ссылка/указатель (IsRef).

## Описание типов и литералы

- **FmtChar / FmtWide** — модификаторы StrChar и StrWide для printf-стиля форматирования.
- **Bool** — три состояния: `true`, `false`
- **None** — флаг "не инициализировано" в runtime-значении, не тип.
- **Integers** — только signed. Unsigned вынесен в отдельную категорию для FFI и битовой арифметики.
- **Tensors** — реализация через LibTorch (DenseTensor, SparseTensor). DeviceTensor добавляется при поддержке GPU.

## Алиасы (синонимы)

Алиас — альтернативное имя для существующего типа. Один тип может иметь несколько алиасов.

| Алиас | Базовый тип | Назначение |
|-------|-------------|------------|
| Any | Void | Обобщённый тип |
| Char | Int8 | Символ UTF-8 |
| Byte | UInt8 | Беззнаковый байт |
| Word | UInt16 | Беззнаковое слово |
| DWord | UInt32 | Беззнаковое двойное слово |
| DDWord | UInt64 | Беззнаковое четверное слово |
| Single | Float32 | Число с плавающей точкой (4 байта) |
| Double | Float64 | Число с плавающей точкой (8 байт) |
| FmtChar | StrChar | Строка с printf-форматом |
| FmtWide | StrWide | Широкая строка с printf-форматом |
| Vector | List | Упорядоченный список |
| Map | Dict | Словарь ключ-значение |

Алиас **не может** совпадать по имени с категорией (например, нет алиаса Integers → Int64, Strings → StrChar).

## Спецификация для парсера

Парсер оперирует следующими правилами при разборе типов:

1. **Имя типа** начинается с `:` и может быть:
   - Конкретным типом: `:Int32`, `:StrChar`, `:Bool`
   - Обобщённой категорией: `:Integer`, `:Number`
   - Алиасом: `:Byte`, `:Double`, `:Vector`
   - Составным типом с модификатором: `:Int32*` (IsRef)

2. **Модификаторы типа**:
   - `*` — IsRef (указатель/ссылка)
   - `[...]` — размерность тензора
   - `(...)` — параметры шаблона

3. **Арифметические типы** (все, кроме Rational и Complex):
   - Trivially Copyable
   - Могут быть элементами тензоров
   - Участвуют в type promotion

4. **Logical (Bool)**:
   - Не участвует в арифметическом продвижении
   - `Bool + Integer` → ошибка компиляции
   - Ternary logic: `true`, `false`, `unknown`

5. **Unsigned**:
   - Не участвует в автоматическом продвижении
   - Только для FFI и битовой арифметики
   - Требует явного преобразования в signed

Детали реализации идентификатора типа и битовой раскладки — в `include/types/ARCH.md`.
