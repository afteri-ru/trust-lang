## Architecture

Менеджер пакетов — **отдельный компонент** (`include/pm` + `src/pm`), поставляется как
самодостаточное приложение `trust-pm` с контрактом **CLI + машиночитаемый JSON** (версия
протокола, `capabilities`, структурированные ошибки). Компилятор с ним взаимодействует только
по этому контракту (сеть/TLS — в PM, не в компиляторе).

Слои: `protocol` (конверт ответа и коды ошибок), `manifest` (содержимое манифеста),
`resolver` (решатель зависимостей), `cache`/`net` (кэш + сеть), `cli` (диспетчер команд).
Формат `.trust` и работа с деревом/архивом вынесены в разделяемый компонент `packages`
(`packArchive`/`unpackArchive`/`listEntries`/`readArchiveEntry`, маркер `kManifestFileName`).

- **Формат `.trust`** (tar+zstd, детерминированно, портативен) и композиция (манифест = граница,
  вложенные пакеты) — реализованы в `packages`.
- **Манифест** `trust.pkg.json`: документ (маркер границы + `schema`/`name`/`version`/
  `dependencies` + прочие поля) парсит `packages` (`packages::Manifest`, версия — данные);
  semver-строгость/интерпретацию версии выполняет `pm` как потребитель; человекочитаемое
  описание — отдельный `README.md`.
- **Версия** — только семантическое ядро `MAJOR.MINOR.PATCH`. Диапазоны: `*`,
  `=`, `>=`, `>`, `<=`, `<`, `^`, `~`, конъюнкция через `,`.
- **Решатель** — `libsolv` (кандидаты подаются как solvables с `provides name=evr`; диапазон
  раскладывается в конъюнкцию отношений). Выбирается один набор (по одной версии на имя).
- **Кэш** — контент-адресуемый по sha256 (`<cache>/artifacts/<sha256>`), защита от
  параллельных запусков — `flock` (`<cache>/lock`). Целостность **внешняя** (индекс/lock),
  не в манифесте.
- **Lock** — `trust.lock.json` рядом с манифестом; `--frozen` читает только его, `--offline`
  запрещает сеть и обслуживает из кэша (по sha256 из lock).

## Facts and invariants

- **Слой загрузки `libsolv` несовместим с C++20 по имени поля `Solvable::requires`** (ключевое
  слово C++20). В TU, включающем `<solv/*.h>`, имя переопределяется через
  `#define requires solv_requires` до включения заголовков; поле читается как `solv_requires`.
- **Детерминизм `.trust` обязателен**: повторная упаковка → тот же архив (байт-в-байт) и sha256.
- **Интегральный контроль не внутри манифеста** (иначе самоссылка): sha256 хранится во внешнем
  слое (индекс источника, `trust.lock.json`), кэш ключуется им же.
- `--frozen`/`--offline` не должны обращаться к источнику: пакет обслуживается из кэша по
  sha256 из lock; локальный путь из lock может быть уже недоступен.
- **Формат/архив/хеш — из общих слоёв:** `packages` (архив, маркер `kManifestFileName`,
  `PackageException` — код уходит в JSON-конверт как есть), `utils/hash.hpp` (sha256).

## Decisions

- Переиспользуются **библиотеки**, а не сторонний менеджер пакетов: `libsolv` (решатель),
  `libarchive` (tar), `libzstd` (сжатие), `libcurl` (сеть/TLS), `nlohmann_json` (JSON),
  `llvm::SHA256` (целостность). `libmamba`/conda-формат не используются: conda-пакет —
  платформенно-специфичный бинарный артефакт, а `.trust` — портативный пакет исходников.

## Relations

- Контракт с компилятором — CLI+JSON; вызов `trust-pm` из `trust` (см. `include/pipeline`).
- Разделяемый компонент `packages` — формат `.trust`, pack/unpack, модель/поиск; `pm` его
  потребитель (линкует `packages_lib`).
- Пользовательская документация — `docs/content/ru/docs/modules.md` (первоисточник).
