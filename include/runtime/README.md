# Runtime — Среда выполнения

## Назначение

Среда выполнения для языка TrustLang: type-erased контейнер значений (Var), механизмы обработки исключений (try-all/try+), инициализация стандартной библиотеки и встроенные функции.

## Особенности реализации

- **Type-erased контейнер** — `Var` хранит значение любого `TypeKind` с динамическим dispatch (boxing/unboxing).
- **Исключения** — try-механизмы (try-all, try+) с поддержкой вложенных блоков и автоматической очистки стека.
- **Стандартная библиотека** — инициализация stdlib при запуске, встроенные функции для работы с тензорами (libtorch), dict и var.
- **Зависимости** — только от `types` (система типов), не зависит от компиляторных компонентов.
