# Semantic — Семантический анализатор

## Назначение

Выполняет семантический анализ AST: рекурсивный обход дерева, построение таблицы символов и проверку корректности имён и типов. Phase 1 охватывает объявления переменных с инициализацией, литералы в выражениях, валидацию дубликатов имён и неопределённых типов.

## Особенности реализации

- **Рекурсивный обход AST** — анализатор обходит дерево, формируя SymbolTable в Context.
- **SymbolTable** — хранит все объявленные имена с их типами и позициями в исходном коде; доступна через `Context::symbols()`.
- **Валидация** — проверка дубликатов имён, неопределённых имён и типов, отсутствующих инициализаторов.
- **Pipeline position** — расположен между Parser и CppTranspiler; при ошибках семантики генерация C++ не запускается.
