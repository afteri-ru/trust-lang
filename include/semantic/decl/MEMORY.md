## Architecture

Анализаторы объявлений: `DeclAnalyzer` — фасад, делегирует `VarDeclAnalyzer`/`FuncDeclAnalyzer`/
`DestructureAnalyzer`; type-объявления (typedef/enum/variant/record/class, native-шаблон-тип) — в type-файлах
фасада. Проверки сигнатуры — `func_signature_check` (`validate*` — fatal, `check*` — report-only); порядок
вызовов — `analyzeFuncDecl`. Дополнительно: `exported_signature_check`, `type_completeness`.

## Facts and invariants

- **⚠ Экспортируемая сигнатура не содержит file-private типов:** `exported_signature_check` обходит граф типа
  (`forEachTypeChild` + базы) и даёт error при объявлении.
- **⚠ Полнота «по значению» (`type_completeness`):** неполнота = ВИДИМЫЙ forward из ДРУГОГО файла (видимая
  декларация из экспорт-набора), а НЕ `isCompleteType` реестра; в файле владельца forward до определения
  допустим; `unique` к неполному — ошибка. Определение за forward'ом интерфейса помечено
  `isExportImplementation` и в экспортную поверхность НЕ входит. **Cross-file — по МЕСТУ ДИАГНОСТИКИ (`range`),
  а не по узлу аннотации:** при опущенной аннотации узел типа принадлежит callee, поэтому вывод
  (`h := make();`) проверяется по возвращаемому типу callee; узел-маркер `&&`/`&*` разворачивается до имени.
- **⚠ Record-типы (Struct/Class) — единый анализ:** `:Struct` → POD, `:Class`/пользовательский → классы.
  **`baseClasses` — ОТДЕЛЬНОЕ поле дескриптора, НЕ `baseType`:** иначе `getDesugaredTypeId()` схлопнул бы
  производный в базовый. Struct не наследует — ошибка. Forward `:= ...` для поля — ошибка; Struct default
  ЗАПРЕЩЁН (NSDMI), только `:= _`. **⚠ POD-предикат поля — ЧАСТИЧНЫЙ (`decl/pod_predicate.hpp`, R4/R13):**
  семантика отвергает только ЗАВЕДОМО не-POD поля (класс-инстанс, ссылки-обёртки/ссылки, строки, `Any`,
  изменяемый массив); неизвестные/нативные типы остаются вердикту C++ `static_assert` (R4 — layout не
  моделируется). Шаблон-классы: класс-скоуп до резолва баз; конструктор `Box(...)` — по
  типу-цели. `@[virtual]`/`@[override]` — не реализованы: явная ошибка.
- **⚠ Forward-объявление классов/шаблон-классов (`X ::= %std::...{...};`)** — узел `ClassDecl`, обрабатывается
  из `analyzeTypeDecl` (узел-ребёнок в `analyzeNode` — no-op, иначе двойная регистрация). Методы/поля — через
  `addMethod`; **поле без типа или не-найденное — ERROR, НЕ `Any`.** Члены: статический — имя с `::`, 
  экземплярный — без. Шаблонность ВЫВОДИТСЯ из `m_template`.
- **⚠ `:A ::- T;` — ВТОРОЕ имя существующего типа (не новый):** тот же `TypeId`; LHS вводится как НОВОЕ имя и
  обязан быть свободен. `=` — ТОЛЬКО для реализации/доопределения объявленного типа по RHS record/native.
  Экспортируемый синоним — `checkExportedTypeVisibility` (private — ошибка).
- **⚠ `-Wbuiltin-override` (дефолт warning):** повторное `=`-определение уже реализованного builtin-типа
  (напр. GMP + OpenSSL длинных чисел) — переопределение встроенного ТИПА (НЕ модуля). Первая реализация
  сохраняется, повторная игнорируется; `-Wbuiltin-override=ignore` гасит диагностику.
- **⚠ `=`-тело builtin: строгое ПОКРЫТИЕ + «шире интерфейса»:** каждый интерфейсный метод builtin-типа
  (из дескриптора) обязан иметь член `=`-тела (`%name`/`name`) — иначе error «interface method … has no
  implementation»; лишние члены (не из интерфейса) допустимы (объявляют доп. C++-члены, интерфейс Trust
  не расширяют). `@[override]` без цели — ошибка.
- **Методы:** `findMethod` односторонний (обычное имя находит и обычный, и нативный метод); инвариант «одна форма
  имени».
- **Деструктуризация `t1..tN := [...]`** — точная привязка по арности; вложенная не поддерживается;
  rest-цель == источник — `pop_front`; аннотация на rest-цели — Error.
- **Нативные шаблоны-типы** регистрируются абстрактным шаблоном (НЕ как функция); резолв `vector<Int32>`
  интернирует инстанциацию; дубль C++-имени со встроенным — Warning.
