# Solver - SMT-решатель

## Назначение

Компонент для формальной верификации программ TrustLang: генерация SMT-LIB 2 формул и опциональная интеграция с Z3 для доказательства корректности контрактов (предусловий, постусловий, внутренних утверждений).

## Особенности реализации

- **SmtAst / SmtPrinter** - AST-узлы для SMT-LIB 2 выражений (термы, сорты, команды) и конвертация в текстовый SMT-LIB 2 формат (работает без Z3). При `--solver-mode=export` рядом с `.smt2` создаётся файл отображения `.smt2.map` (SMT-символы и `(assert ...)` → trust-файл/диапазон/имя).
- **SmtOp** - встроенные операторы как `enum class SmtOp` из X-макроса `SOLVER_OPERATOR_LIST` (единый источник имён; диспетчер `SolverZ3` использует `switch (term.op)`, без строковых сравнений).
- **Source-привязка** - `SmtTerm`/`SmtCommand` несут `srcRange` (диапазон trust-узла); в `SmtScript::symbolMap` собирается маппинг `SMT-имя → {trust-имя, диапазон}` (параметры, функции, глобалы).
- **SolverInterface** - абстрактный интерфейс для бэкендов SMT-решателей (включая `getModelValue` - значение константы из модели для отчёта о контрпримере).
- **SolverZ3** - реализация через Z3 C API (включается опцией `WITH_SOLVER=ON`).
- **SolverStub** - fallback-заглушка при `WITH_SOLVER=OFF`, возвращает `kUnsupported` (верификация недоступна).
- **Независимость** - SMT-LIB 2 генерация работает без Z3; Z3 - опциональная зависимость только для доказательства.
- **Целые типы** - `kIntegers`→знаковые BV-операторы (`bvs*`), `kUnsigned`→беззнаковые (`bvu*`); поддержаны битовые операторы (`bvand/bvor/bvxor/bvnot/bvshl/bvashr/bvlshr`).
- **Термины решателя** - `old` (начальное значение), `result` (результат функции), `forall`/`exists` (кванторы) мапятся в SMT-LIB 2; `fresh`/`length` - вне поддержки (диагностика).
