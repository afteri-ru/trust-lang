# Formatter - pretty-printing исходного текста Trust

## Назначение

Форматирование исходников Trust (этап форматирования драйвера): расстановка переводов строк и пробелов
между токенами, отступы, сохранение комментариев и «вербатим»-фрагментов. Публичный API —
`formatter/format.hpp`.

## Особенности

- **Конвейер:** `Parser` отдаёт поток токенов и классификацию макросов; строится модель токенов с
  0-based offset'ами, зазоры разбирает `parseGap` (пробелы/`#`-комментарии/`/*...*/`; прочее — verbatim),
  затем `Emitter` одним проходом выводит зазоры/комментарии и вычисляет перевод строки/пробел/отступ.
- **Конфиг `.trust-format`** (поиск вверх по дереву, как clang-format); `FormatOptions` и x-macro
  `KEYWORD_SIGIL_LIST` — единый источник значений для конфига/CLI/dump. Неизвестный ключ/значение —
  ошибка, без silent fallback.
- **CLI-команда `--format`/`--format-check`** — чтение файла, конфиг, вывод/проверка; не зависит от `pipeline`.
- Детали стадий — в `impl/` (`format_model`/`token_gap`, `emitter`). Инварианты — `MEMORY.md`.
