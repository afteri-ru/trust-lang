## Architecture

Правила Flex (`lexer/lexer.l`), сгенерированные в `<build>/syntax`; лексер подаёт термины в буфер,
который читает `Macro`/`Parser`.

## Facts and invariants

- **Кавычки литералов:** `"…"` → StrChar, `'…'` → StrWide; raw-строки — по ограничителю (`R"`/`R'`).
- **Составные присваивания `+= -= *= /= //= %=` — отдельный терминал (Kind `AssignOp`);** арифметика
  `+ - * / // %` — `MathOp`. Различать только по kind, не по тексту.
- **⚠ `++`/`--` — префикс и постфикс имеют ОДИНАКОВЫЙ `text()`;** позицию кодирует СЛОТ операнда.
  Лексерные правила двухсимвольные (flex longest-match обходит `-->`/`<->`, но `a--b` без пробелов
  лексится как `a--` `b`). `%expect` от них не меняется.
- **⚠ `:-`/`::-` — операторы алиасов:** lexer longest-match обходит `:=`/`::=`/`::` (`a:-1` меняет
  лексику — проверено тестами). `=` НЕ создаёт имён (только присваивание и реализация объявленного типа).
- **⚠ `<<EOF>>` глобального правила обязан `terminate()`** — иначе Flex повторно вызывает yylex на том же
  EOF → бесконечный цикл. Строковые состояния своего `<<EOF>>` не имеют; незакрытая строка без `\n`
  не репортится.
- **⚠ Лексема NONE:** голый `_` — отдельный токен (НЕ NAME); в name-позициях — `NAME "_"`, в
  `catch_arg` — catch-any; `none` — DSL-макрос → `_`; идентификаторы с ведущим `_` — NAME.
- **Форматтер не должен терять исходник после ошибки лексера:** незакрытая строка/комментарий «съедают»
  хвост; при `parseGap == verbatim` хвостовой зазор до EOF сохраняется вербатим.
