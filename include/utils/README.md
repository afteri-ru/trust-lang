# Utils - Вспомогательные утилиты

## Назначение

Набор вспомогательных компонентов, используемых другими модулями проекта: работа с файлами, URI, строками, ошибками, кешированием, ELF, backtrace и транспортом.

## Особенности реализации

- **file_io** - чтение/запись файлов (`FileIO::read<std::vector<char>>`/`read<std::string>`, `write`), работа с временными файлами и директориями.
- **URI** - парсинг и формирование URI (`uriToFilePath`, `filePathToUri` с URL-encoding, `resolvePath`, `uriEncodePath`).
- **strings** - строковые утилиты: trim, tokenize, isNumber, extractName, `fileNameOf`/`shortenedPath` (имя файла; каталоги → `.../`), `prefixEachLine` (префикс на каждую строку — для отладочного вывода), конвертация имён (`nameToCpp`/`cppToName`: `%`-нативные срезаются как есть, ведущий `$`-сигил локальной переменной срезается перед манглингом, обычные манглируются префиксами `c_`/`cpp_`/`ru_`/`u8_`), единый C++-маппинг имён (`cppNamespacePath` — namespace-сегменты, `cppIdent` — один сегмент с EXPECT на `::`, `qualifiedCppName`/`cppDeclName`), маски импорта (`ImportMasks` — единственный парсер/матчер: `utils/import_masks.hpp`; правило видимости сайта — `types/names.hpp`), конвертация trust-имён в C++-вставках `{% ... %}` (`transformEmbedCpp`/`extractEmbedNames`, маркеры `$`/`@`).
- **error (FAULT/EXPECT)** - макросы для проверки инвариантов и фатальных ошибок с диагностикой.
- **cache** - `LruCache` (O(1) по времени) и `SparseCache` для хранения результатов дорогих операций.
- **ELF** - чтение ELF-заголовков и секций (используется debug для `.debug_trust_map`).
- **backtrace** - получение и форматирование stack trace для диагностики.
- **trace** - отладочный вывод компилятора: макрос `TRUST_DEBUG` (произвольные сообщения) с обязательной фильтрацией по ключевым словам/маскам; авто-токены фильтра из `__FILE__` (root/path/component/rel/stem/file) + явные теги. При отключенной отладке (`TRUST_TRACE_ENABLED=0`) макрос вырезан. Фильтр задаётся из `.src` макросами `@__DEBUG__`/`@__DEBUG_SCOPE__`; дамп скоупа - `semantic/debug_scope.hpp` (`TRUST_SCOPE`).
- **trace_options** - единый реестр (x-macro) именованных опций дампа скоупа (`level`, `names`, `types`, `max`, `count`): имена, допустимые значения, описание и текст-подсказка со всем списком. Значения задаются без кавычек (`level=all`, `max=10`); строкой - только фильтр-значение (`names="x*"`). Используется и парсером макроса (валидация + диагностика), и семантикой (применение к `ScopeDumpOpts`).
- **transport** - низкоуровневый ввод/вывод (read/write с таймаутами, non-blocking).
