# Utils — Вспомогательные утилиты

## Назначение

Набор вспомогательных компонентов, используемых другими модулями проекта: работа с файлами, URI, строками, ошибками, кешированием, ELF, backtrace и транспортом.

## Особенности реализации

- **file_io** — чтение/запись файлов, работа с временными файлами и директориями.
- **URI** — парсинг и формирование URI (схема, хост, путь, query).
- **strings** — утилиты для работы со строками (split, join, trim, форматирование).
- **error (FAULT/EXPECT)** — макросы для проверки инвариантов и фатальных ошибок с диагностикой.
- **cache** — LRU-кеш для хранения результатов дорогих операций.
- **ELF** — чтение ELF-заголовков и секций (используется debug для `.debug_trust_map`).
- **backtrace** — получение и форматирование stack trace для диагностики.
- **transport** — низкоуровневый ввод/вывод (read/write с таймаутами, non-blocking).
