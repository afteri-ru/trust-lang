# Analysis - продукты анализа

## Назначение

Типы, разделяемые анализатором (`semantic`) и кодогенерацией (`transpiler`), плюс value-типы
поведенческих режимов компилятора.

## Состав

- **`symbol_table.hpp`** - `SymbolTable` (стек лексических скоупов) и `Symbol`; единый источник имён и
  их типов во время семантического прохода; кодоген читает её как источник типов/сигнатур.
- **`symbol_index.hpp`** - `SymbolInfo`/`SymbolIndex`: плоский индекс объявлений (имя/тип/диапазоны) для
  LSP-навигации.
- **`modes.hpp`** - `SolverMode`, `StackCheckMode`, имена нативных функций контроля стека,
  `BehavioralModes` и чистые предикаты. Владелец `FlagKind` - `semantic`; значения разрешаются им же
  (`semantic::behavioralModesFromOptions`) и передаются в кодоген как данные.

## Принцип

Компонент расположен НИЖЕ `semantic` и `transpiler`: кодогенерация не зависит от анализатора.
