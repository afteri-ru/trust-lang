NewLang v0.2.0

Friday, August 12, 2022
Tags:
  • Release
  • Trust-Lang

Attention!!!

This article contains a description of the syntax of the previous version of NewLang.

The current version of the language syntax can be viewed here.

NewLang is a high-level programming language in which one can combine standard algorithmic constructs with declarative programming and tensor computations for machine learning tasks.

The main feature of the language is a simple, logical and non-contradictory syntax, which is based not on the use of reserved keywords, but on a strict system of grammar rules using punctuation marks (the list of which also includes the operators of the language).

NewLang is in the process of active development, and this is the second public release, in which substantial new capabilities have been added and some changes have occurred compared to the previous version.

Language features:

  • The ability to work both in interpreter and compiler mode*.
  • Dynamic and static typing with the ability to specify types explicitly.
  • Static typing is conditionally strict (there is no automatic type casting, but conversion between some data types is allowed, for example, an integer can be automatically converted to a real or rational one, but not vice versa).
  • Automatic memory management.
  • OOP in the form of explicit class inheritance and “duck” typing.
  • At the syntax level, support for several types of functions (ordinary and pure functions without side effects).
  • Optional and named function parameters.
  • Inserts of code in the implementation language (C/C++) are possible*.
  • Simple integration with already existing software libraries (including the import of native variables and functions from C/C++).

New global features:

  • Macros added. Now one can make one’s own language dialects and use a more familiar notation of algorithmic constructs with keywords. For example, the loop
[ cond ] <-> {
      loop body
};

can be written in a more familiar notation

\while (cond) {
      loop body
};
  • Iterators added for iterating over the elements of dictionaries or for queries to other containers (for example, to databases). At the level of the base syntax, data filtering is supported, including a functional analog of LINQ through the use of callback functions as a filter condition.
  • A new data type added — rational numbers with unlimited precision. They are written in the form of an ordinary fraction whose separator is a backslash, for example one can be written as 1\1, and the number 0.5 as 1\2.
  • The dictionary unpacking operator … (ellipsis) has been implemented, which can be used to pass several arguments in a function call or to assign a value to several variables at once.
  • Now the assignment operator supports setting values to several variables at once. On the right side of the assignment operator there can be one or several values or the dictionary unpacking operator. Moreover, the dictionary can also be specified on the left side of the assignment operator, and thus one can write the simplest way to iterate over all its elements, when in the loop the first element of the dictionary is saved to the variable item and is removed from the dictionary itself:
[ dict ] <-> {  
      item, dict := ... dict; 
};

Changes in the syntax:

  • The notation of loops has changed. Instead of two different types with a precondition and a postcondition, a unified notation form is now used, and the type of the loop is determined by the relative position of the condition and its body.
  • The names of arithmetic and some other data types have been changed to more logical ones. The names of arithmetic types now indicate their size (Int8, Int16 … Float32, Float64, etc.).
  • Multiline comments have become nested

Code examples

``` #!../output/nlc --eval

Definition of the hello function

hello(str) := {

# Import of a standard C function
printf := :Pointer('printf(format:FmtChar, ...):Int32');

# Calling a C function with type checking of the arguments against the format string
printf('%s', $str);  

# Returning a value from the hello function
 $str;

};

hello(‘Hello, world!’); # Call the function

Output (the first line is output by printf, and the second is the return value of the hello function):

Hello, world!
Hello, world!
