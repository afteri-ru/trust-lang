## Architecture

TrustLang - высокоуровневый язык общего назначения для безопасной (trusted) разработки.
Реализован как транспилятор в C++: безопасное управление памятью без сборщика мусора,
обнаружение ошибок управления памятью и гонок данных на этапе компиляции. Поддерживает
тензорные вычисления (LibTorch), рациональные числа с неограниченной точностью, статическую
и динамическую типизацию, именованные и опциональные параметры функций, глубокую
интеграцию с экосистемой C/C++.

Архитектура отдельных компонентов описана в пер-компонентных файлах `MEMORY.md`, расположенных
в соответствующих каталогах (по одному на каталог/компонент). Правило, что любой каталог может
содержать свой `MEMORY.md`, и перечень компонентов - см. в `AGENTS.md` (раздел «Persistent
Memory (`MEMORY.md`)»).

Единый источник истины об архитектуре и персистентной памяти - файлы `MEMORY.md`; для
документации пользователя/справки используется `docs/` (исходники на русском,
`docs/content/ru`), а `README.md` - краткий обзор. Подробности см. в `AGENTS.md`
(раздел «Persistent Memory (`MEMORY.md`)») и `.clinerules/README.md`.

## Facts and invariants

- Тесты всегда адаптируются под изменения кода, никогда наоборот (AGENTS.md, правило 10):
  если изменение осознанно меняет поведение/структуру (форма AST/term, грамматика, codegen) -
  обновить затронутые тесты под новую модель, НЕ откатывать корректное изменение ради старых
  тестов. Это касается и parser-тестов, закрепляющих внутреннюю структуру term/AST.
