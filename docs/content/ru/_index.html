TrustLang - это высокоуровневый язык программирования назначения для безопасной (trusted) разработки, в котором исопльуется безопасное управление памятью без сборщика мусора и обнаружение ошибок управления памятью и гонки данных на этапе компиляции. Испольуется как статическая, так и динамическая типизация с автоматическим выведеним типов, именованные и опциональные параметры функций.
Компилятор языка реализован как транспилятор в код C++ и полностью интегрируется его экосистемой.
На уровне синтаксиса поддерживается контрантное программирование и доказательстов корректности (Z3), тензорные вычисления (LibTorch) и рациональные числа с неограниченной точностью (gmp).

Зачем нужен TrustLang?

Постоянное усложнение синтаксиса современных языков повышает порог входа и усложняет поддержку кода. TrustLang создан как «надстройка» над C++, лишённая этих недостатков. Подробнее - в разделе «Концепции».

{{% /blocks/section %}} {{% blocks/section %}}

Пример скрипта Hello world! на TrustLang


    hello(str:StrChar) := {
        @print('call: {}\n', str);
        str;
    };

    @main() := {
        hello('Привет, мир!');
    };
Вывод: 
    call: Привет, мир!
    Привет, мир!

Пример вычисления факториала 40 на TrustLang с использованием DSL синтаксиса


    #!../_build/trust --run

    @main() := {

        $fact := 1\1; # Рациональное число 1 (без ограничения точности)
        $mult := 1;

        @while( mult <= 40 ) {
            fact *= mult;
            mult += 1;
        };

        # Print result
        @print('{}', fact);
    }
Вывод: 
    815915283247897734345611269596115894272000000000\1
