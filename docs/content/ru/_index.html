Высокоуровневый язык общего назначения для доверенной (trusted) разработки с безопасным управлением памятью без сборщика мусора и  обнаруженим ошибок (включая гонки данных), на этапе компиляции и  полная совместимость со всей экосистемой C/C++ (включая вставки фрагментов C++ кода).

У всех современных языков программирования синтаксис постоянно усложняется с выходом каждой новой версии (стандарта). Это вынужденная плата за развитие языка и постоянное повышение "налога" на вход для новичков.

TrustLang — это язык-«надстройка» над C++, который предназначен для пользования всеми богатыми возможностями C++ , но без его недостатков в виде очень сложного синтаксиса, неопределного поведения и прочих подводных камней.

Синтаксис языка построен на основе грамматических правилах без использования ключевых слов, а встроенный макропроцессор способен реализовать какой угодно синтаксис или расширить уже существующий DSL диалект.

Безопасная работа с памятью, тензоры и рациональные чилса неограниченной точности доступны «из коробки», а скомпилированный код — это обычный C++ , поэтому всё, что умеет C++ , доступно и здесь. Подробнее — в концепциях языка.

Почему TrustLang?

Безопасная память без сборщика мусора

Управление памятью в стиле C++ с помощью сильных и слабых ссылкок (RAII). Выявление ошибок, включая гонки данных, на этапе компиляции и обработка stack overflow как обычного исключения вместо segfault. Модель памяти →

Синтаксис без ключевых слов + DSL

Грамматические правила вместо ключевых слов — это простой и быстрый парсер, а макросы позволяют расширять синтаксис и использовать привычные ключевые слова. Макросы и DSL →

Система типов

Статическая и динамическая типизация. Тип можно указать явно или оставить автоматический вывод из контекста. Импорт нативных типов и шаблонов C++. Система типов →

Числа «из коробки»

Рациональные числа неограниченной точности и тензоры (LibTorch) — базовые типы данных с поддержкой на уровне синтаксисе. Возможности →

Интеграция с C/C++

Непосредственные вызовы C++ функций, вставки C++-кода, (а внтури него даже ассемблера) и использование стандартной библиотеки без FFI-обвязок. Интеграция →

Формальная верификация

Контрактрное программирование (пред/пост-условия, утверждения). Экспорт кода и контрактов в SMT-решатель (Z3). Верификация →

Как это выглядит

Пример простой программы на TrustLang с числами неограниченной точности, автоматическим выводом типов и привычными ключевыми словами из DSL-макросов: 


    #!../_build/trust --run -Wsigil=ignore

    fact := 1:BigIteger;
    mult := 1;

    while( mult <= 40 ) {
        fact *= mult;   # факториал 40, точность не теряется
        mult += 1;
    };

    @print('{}', fact);

Вывод:

    815915283247897734345611269596115894272000000000
