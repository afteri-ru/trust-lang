### Словарь

Словарь (*:Dictionary*) - набор данных произвольного типа с доступом к отдельным элементам по целочисленному индексу 
или по имени элемента при его наличии (это похоже и на tuple и на структуру одновременно). 

Словари отличаются от [тензоров](https://trust-lang.net/type_nor.html) тем, что всегда имеют только одно измерение, 
но каждый элемент может содержать произвольное количество элементов любого типа, в том числе и другие словари.

Доступ к элементам словаря происходит по имени элемента, которое записывается через точку от имени переменной, либо по целочисленному индексу. 
Индекс начинается с 0 и как у тензоров, тоже может быть отрицательным (индекс элемента от "конца").

Литерал с типом «словарь» в тексте программы записывается в круглых скобках с обязательной завершающей запятой, т. е. `(,)` - пустой словарь, `(1, 2= «2», name=3,)`. Для указания конкретного типа объекта у литерала, его необходимо указать после закрывающей скобки, т.е. `(1, two= «2», name=3,):Dict`.
Позиционный литерал без указания типа, например `(1, 2, 3,)`, всегда является словарём (`:Dictionary`). Словарь - единственный универсальный тип, который может быть приведён к любому другому типу: для создания значения конкретного типа достаточно передать словарь аргументом в приведение/конструктор типа, например `:Tensor[...]( (1,2,3,) )`.

### Перечисление (Enum) {#enum}

*Enum* - тип данных с ограниченным списком членов, у каждого из которых есть имя и значение.
Все члены перечисления имеют **единый** тип значений (*valueType*), который выводится по общим
правилам (из значений членов либо из явной аннотации типа).

Литерал-объявление записывается в постфиксной форме `(члены,):Enum` или префиксной
`:Enum(члены)` (как у типизированного кортежа). Обязательная завершающая запятая - как у словаря.

```python
    # Члены с явными значениями; тип значений - Int64 (по общим правилам)
    Status ::= (OK=0, ERROR=1, BUSY=2,):Enum;

    # Безнарные члены - автоинкремент от 0: RED=0, GREEN=1, BLUE=2
    Color ::= (RED, GREEN, BLUE,):Enum;

    # Явный тип члена задаёт единый тип значений - Int8 (безнарные → автоинкремент)
    Flag ::= (LOW:Int8, HIGH,):Enum;
```

{{< unreleased why="оператор `::=` здесь используется корректно (объявление типа Enum); проверено компилятором. Однако доступ к членам через `Status.OK` и методы `count()`/`fromName()`/`fromValue()` в текущей версии реализованы не полностью (например `Status.count()` даёт ошибку 'type Enum has no method count')" />}}

По умолчанию тип значений выводится из явных значений членов (resolvedType + join по общим
правилам); если явных значений нет - минимальный знаковый целый по числу членов. Явная
аннотация типа члена (`name:Type`) задаёт тип значений принудительно (у всех членов он должен
быть одинаковым). Сравнение членов идёт **по значению** (value), а не по позиции (IntEnum-семантика).

Классические методы (работают через имя типа):

- `count()` - число членов;
- `fromName(name)` - член по имени;
- `fromValue(value)` - член по значению.

Обращение к члену - через имя типа: `Status.OK`.

### Вариант (Variant) {#variant}

*Variant* - гетерогенный тип: каждый член имеет **свой** тип данных (аналог `std::variant`).
Тип члена задаётся явной аннотацией (`name:Type`) либо выводится из его значения; для
безнарного члена без типа - минимальный знаковый целый по позиции.

```python
    Data ::= (i=42, s='text', r=1\2,):Variant;   # типы членов: Int8, StrChar, Rational
    V    ::= (X:Int64=7, Y:Rational,):Variant;   # явные типы членов
```

{{< unreleased why="оператор `::=` здесь используется корректно (объявление типа Variant); проверено компилятором" />}}

Классический метод: `count()` - число членов. Обращение к члену: `Data.i` (тип - тип
конкретного члена, гетерогенный).
