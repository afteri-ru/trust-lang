Компилятор `trust` - драйвер конвейера: читает исходный `.src`-файл, выполняет
лексический/синтаксический анализ, семантический анализ, транслирует AST в код C++
(`.cppt`) и собирает исполняемый файл через внешний C++ компилятор.

## Справка

У драйвера две независимые команды справки («двухсправочная модель»), обе
генерируются централизованно из таблиц опций/диагностик:

- `--help` - справка по опциям драйвера, сгруппированная по категориям
  (`General`, `Input & Output`, `Compilation model`, `Linking`, `Toolchain`,
  `Project-specific`).
- `-Whelp` - центральная справка по диагностикам, сгруппированная по `DiagGroup`
  и агрегатам `WarnGroup` (см. [Диагностика](../diagnostics/)).

## Линковка рантайма (`--link-runtime`)

Типы, опирающиеся на библиотеку времени выполнения (например, `Rational`),
требуют trust-runtime, которая собирается и как динамическая (`trust-runtime.so`),
и как статическая (`trust-runtime.a`). При компиляции исполняемого файла конвейер
линкует рантайм в соответствии с `--link-runtime` (по умолчанию **`static`**):

- `static` - код рантайма линкуется в исполняемый файл из `trust-runtime.a`;
  результат самодостаточен и работает без `trust-runtime.so`.
- `shared` - исполняемый файл линкует `trust-runtime.so` динамически и разрешает её
  во время выполнения через `LD_LIBRARY_PATH` / каталог запуска.

## Сборка C++ кода

Pipeline генерирует рядом с `.cppt` два файла:

- `Makefile` - шаблон, встроенный в trust (содержит `kMakefileBuild`).
- `build.conf` - конфигурация с опциями компиляции, переданными через командную
  строку (компилятор, флаги).

Параметры Makefile по умолчанию берутся из CMake (компилятор, стандарт `-std=c++23`,
include path) и могут быть переопределены через `build.conf` или переменные окружения.

## Генерируемые C++ файлы

Каждый сгенерированный `.cppt` (и входной файл `_main.cppt`) начинается с
автогенерируемого заголовка (первая строка: имя проекта, полная версия компилятора,
дата/время генерации). Файл `LICENSE` копируется в каталог сборки рядом с
сгенерированными `Makefile`/`build.conf` (текст лицензии не встраивается в
сгенерированные C++ файлы).
