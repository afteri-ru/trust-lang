Экосистема инструментов TrustLang включает компилятор `trust`, языковые серверы
LSP/DAP (`trust-lsp`, `trust-dap`) и расширение для VSCode.

Дополнительно в проект входят [песочница (playground)](/ru/playground/) с живой
пере-транспиляцией в C++.
