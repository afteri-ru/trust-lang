## Фундаментальные понятия

Все операторы и управляющие конструкции *TrustLang* подчиняются общим правилам:

- Синтаксис языка основан на [грамматических правилах](../syntax/grammar/), а не на ключевых
  словах. Каждая конструкция существует в двух эквивалентных формах записи:
  **базовый синтаксис** (комбинации специальных символов, например `[ cond ] --> { ... }`) и
  **привычный синтаксис на ключевых словах** через DSL-макросы (`@if`, `@while`, `@func`, ...).
  Общее соответствие «макрос ↔ базовый синтаксис» описано один раз — в разделе
  [Keyword syntax (DSL)](../syntax/dsl/).
- Инструкции (операторы) отделяются друг от друга точкой с запятой **`;`**.
- Любая конструкция является **выражением** и возвращает значение, поэтому её можно вкладывать
  в другие выражения.

## Блоки кода {#block}

Последовательность идущих подряд инструкций группируется в **блок кода** `{ ... }`, который
выполняется как единое целое и завершается точкой с запятой `;`. Блок кода возвращает значение
своей последней инструкции; тип этого значения можно ограничить явно: `{ ... }:Type` либо набором
типов `{ ... }: <:Type1+:Type2>` (знак `-` перед типом исключает его).

Блоки кода используются для ограничения области видимости переменных (см.
[Иерархия кода](../syntax/hierarchy/)) и могут быть именованными — тогда они выступают локальными
метками передачи потока управления (см. [Возврат, прерывания и ошибки](throw/)). Тело функции тоже
является блоком кода в пространстве имён её определения. Перехват и прерывание потока внутри блока
описаны в разделе [throw](throw/).

Блок кода с **нативным синтаксисом** `{% ... %}` содержит исходный текст на языке реализации
(C++), который подставляется в выходной текст напрямую (см. [Взаимодействие с C/C++](../syntax/cpp-interop/)
и [Нативные типы](../types/native/)).
