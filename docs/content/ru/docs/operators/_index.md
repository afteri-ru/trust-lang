В *TrustLang* **любая конструкция является выражением** и возвращает значение, поэтому её можно
вкладывать в другие выражения. Инструкции разделяются точкой с запятой `;`; группа инструкций
заключается в блок кода `{ ... }`. Базовые правила блоков и выражений описаны в
[Синтаксисе](../syntax/).

Обработка аварийных ситуаций и гарантии освобождения ресурсов связаны с моделью
[Памяти](../safety/memory/), а операторы типизации — с [Системой типов](../types/type_system/).
