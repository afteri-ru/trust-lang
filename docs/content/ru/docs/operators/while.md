Для записи циклов используется оператор `<->` (в базовой записи) или макросы `@while`/`@dowhile`
(в DSL). Условие записывается в квадратных скобках; в зависимости от взаимного расположения условия и
тела цикл бывает с предусловием (`while`) или с постусловием (`do while`). Эквивалентные формы:

<table>
<tr><th>Макросы DSL</th><th>Базовый синтаксис</th></tr>
<tr><td><pre><code>@while( cond ) {
    тело цикла
};</code></pre></td><td><pre><code>[ cond ] &lt;-&gt; {
    тело цикла
};</code></pre></td></tr>
<tr><td><pre><code>@dowhile( cond ) {
    тело цикла
};</code></pre></td><td><pre><code>{
    тело цикла
} &lt;-&gt; [ cond ];   # постусловие</code></pre></td></tr>
<tr><td><pre><code>@while( cond ) {
    ...
} @else {
    ...    # если cond == false при входе
};</code></pre></td><td><pre><code>[ cond ] &lt;-&gt; {
    ...
}, [ ... ] --&gt; {
    ...    # ветка else
};</code></pre></td></tr>
</table>

Цикл с предусловием (`while`) поддерживает ветку `else`, которая выполняется, если условие входа в цикл
не было выполнено ни разу.

> **Внимание:** это отличается от аналогичной конструкции в Python, где секция `else` выполняется всегда,
> кроме прерывания цикла по `break`.

## Перебор коллекций (foreach)

У цикла `foreach` нет отдельного ключа DSL — он реализуется циклом с деструктуризацией элемента и
мутацией источника (оператор раскрытия списка). Пример суммирования элементов словаря:

```python
summa := 0;
dict := (1,2,3,4,5,);
[ dict ] <-> {          # условие цикла — пока в dict есть данные
    # распаковка: первый элемент переходит в item, суффикс dict... — оставшиеся
    item, dict... := ... dict;
    summa += item;      # накопление суммы
};
```
