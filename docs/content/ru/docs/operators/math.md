Арифметические операторы *TrustLang* применимы к [числовым типам](../types/numbers/) и формам с
присваиванием. Каждый бинарный оператор имеет парный аналог `op=`, который выполняет операцию и
присваивает результат левому операнду (`a += 1;`):

| Оператор | Действие |
|---|---|
| `+` / `+=` | сложение |
| `-` / `-=` | вычитание |
| `*` / `*=` | умножение (применимо и для повторения строк) |
| `/` / `/=` | деление (результат — число с плавающей точкой) |
| `//` / `//=` | целочисленное деление с округлением к меньшему (как в Python) |
| `%` / `%=` | остаток от целочисленного деления |

Отдельного оператора возведения в степень нет (степень вычисляется функцией/повторным умножением).
Арифметика рациональных чисел и `:BigInteger` — отдельная строгая ветка: смешивание с числами с
плавающей точкой требует явного преобразования (см. [Числа и тензоры](../types/numbers/)).

### Битовые (поразрядные) операторы

Поразрядные операторы в текущей версии **не реализованы**; ранее им соответствовали записи
`.<.` (сдвиг влево), `.>.`/`.>>.` (сдвиг вправо), `.&.`, `.|.`, `.^.`, `.~.` (И/ИЛИ/ИСКЛ-ИЛИ/НЕ).
Статус — в разделе [Статус реализации](../status/).
