## Арифметическое сравнение

Операторы арифметического сравнения — классические `<`, `>`, `<=`, `>=`, `==`, `!=`.
Они применяются для сравнения скаляров и рациональных чисел; операторы равенства `==` и `!=`
позволяют сравнивать и составные значения.

## Сравнение значений

- `==` и `!=` — сравнение с автоматическим приведением совместимых типов для любых объектов.
- `===` и `!==` — точное сравнение для любых объектов (автоматического приведения не выполняется);
  для объектов сравниваются адреса размещения.

## Номинальная (статическая) типизация

Если хотя бы у одной из переменных тип указан явно, то строгая статическая номинальная проверка типов
выполняется автоматически на этапе компиляции. Проверка успешна, если тип правого объекта может быть
автоматически преобразован к типу левого операнда либо присутствует у него в иерархии наследования.

## Динамическая типизация

Проверка типа объекта во время выполнения выполняется операторами с символом тильды.

{{< unreleased why="операторы типизации `~`, `~~`, `~~~` в текущей версии не реализованы как описано: `v ~ :Int32` и `a ~~ (field1=_)` не компилируются" />}}

- `~` — **номинальная** проверка имени типа (класса): истина, если имя класса правого операнда
  присутствует у левого (или есть в его иерархии наследования). Правым операндом может быть тип,
  строковый литерал или переменная строкового типа с именем класса.

  ```python
  name := "class";        # переменная с именем класса
  var ~ :Class;           # сравнение с типом
  var ~ "class";         # имя типа как строка-литерал
  var ~ name;             # имя типа из переменной
  ```

- `~~` — **утиная** типизация. Для простых типов сравнивается совместимость левого операнда по
  отношению к правому; для словарей и классов проверяется наличие всех полей, присутствующих у правого
  операнда (правый — образец):

  ```python
  (field1="value", field2=2,) ~~ ();           # истина (левый операнд — словарь)
  (field1="value", field2=2,) ~~ (field1=_);   # истина (поле field1 есть)
  (field1="value", field2=2,) ~~ (not_found=_);# ложь (поля not_found нет)
  ```

- `~~~` — **строгая** утиная типизация: для простых типов сравнивается идентичность типов без учёта
  совместимости, а для составных — все свойства сравниваются оператором строгого равенства. Пустой тип
  совместим только с другим пустым типом.
