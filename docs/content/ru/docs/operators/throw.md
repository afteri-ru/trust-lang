Последовательность команд ([блок кода](../operators/#block)) можно прервать в любом месте
специальными операторами прерывания. В *TrustLang* используются два вида прерываний, которые по
смыслу соответствуют своей записи:

- **«положительное»** прерывание `++` — возврат значения/сквозная передача потока (аналог `return`);
- **«отрицательное»** прерывание `--` — ошибка (аналог `throw`).

Прерывание может возвращать значение: `++ 'Строка' ++` — вернуть строку, `-- err --` — «бросить»
ошибку (примерный аналог `throw err`). Если значение не указано, прерывание не возвращает ничего
(пустое значение).

## Именованные прерывания: локальный переход и возврат {#named}

Именованные [блоки кода](../operators/#block) могут выступать локальными метками передачи
потока управления. Если перед оператором прерывания указать пространство имён/метку блока, то такое
**именованное** прерывание действует только для указанного блока:

- `block:: ++` — **break** по метке `block` (выход из блока);
- `block:: --` — **continue** по метке (переход на первую инструкцию блока).


Один и тот же фрагмент — именованный цикл с выходом по метке и переходом к началу блока — двумя
формами:

<table>
<tr><th>Макросы DSL</th><th>Базовый синтаксис</th></tr>
<tr><td><pre><code>@loop outer:: {
    @loop inner {
        @break outer;     # break по метке outer (как outer:: ++)
        @continue inner;  # continue — на начало inner (как inner:: --)
    };
};</code></pre></td><td><pre><code>[1] &lt;-&gt; outer:: {
    [1] &lt;-&gt; inner {
        outer:: ++;   # break по метке outer
        inner:: --;   # continue — на начало inner
    };
};
</code></pre></td></tr>
</table>

Тело функции — это блок кода, чьё имя совпадает с полным именем функции. Поэтому «положительное»
прерывание по метке функции возвращает результат из неё (`func_name ++ value ++`); в DSL этому
соответствует `@return`.

Прерывание с глобальной областью видимости `:: ++` завершает работу приложения (аналог `exit`), а
`:: --` — прерывает его без штатного завершения (аналог `abort`).

## Перехват прерываний (try/catch) {#catch}

Неименованные прерывания можно «ловить». Для перехвата используются блоки кода со специальной
семантикой, которые оборачивают тело в `try/catch` по классу прерывания:

- `{+ ... +}` — перехватывает положительные прерывания (`IntPlus`);
- `{- ... -}` — перехватывает отрицательные прерывания (`IntMinus`);
- `{* ... *}` — перехватывает оба типа (`IntAny`).

Статус реализации (важные уточнения):

- **неименованное** `++ value ++` *всегда* бросает `IntPlus` (положительное/сквозное), а
  `-- err --` — `IntMinus` (ошибка), независимо от наличия и глубины обработчиков;
- **именованное** `func ++ value ++` — обычный `return` из функции (метка обязана быть текущей
  функцией или глобальной `::`);
- неперехваченный класс пробрасывается насквозь; сквозной `++` проходит через вызовы функций до
  ближайшего `{+}`/`{*}`;
- перехват значения (например, через `match`) пока не реализован — перехваченное прерывание
  поглощается.

## Обработка ошибок

«Отрицательное» прерывание используется для возврата ошибки лишь условно — оба вида прерываний
равнозначны. Блоки перехвата совместно с оператором [оценки выражения](match/) позволяют
обрабатывать ошибки в классическом стиле try/catch:

```python
[ {*  # перехват всех прерываний (базовый синтаксис)
    op1;
    op2;
*} ] ~> {
    [:ErrorType1] --> { ... };
    [:ErrorType2, :ErrorType3] --> { ... };
    [...] --> { ... };  # default
};
```
