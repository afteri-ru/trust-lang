В этом разделе описан механизм диагностики компилятора TrustLang: предупреждения
и опции `-W`, а также trust-условия и верификация с помощью SMT-решателя.

Diagnostics-модуль (`diag`) отвечает за хранение исходного/выходного кода,
диагностики с привязкой к диапазонам позиций и маппинг позиций между входными и
выходными файлами (для отладки).
