Менеджер пакетов — **отдельный компонент** (самостоятельное приложение `trust-pm`), а не часть
компилятора. Компилятор обращается к нему по контракту «командная строка + машиночитаемый
(JSON) вывод»; управление зависимостями и сеть не встраиваются в компилятор. Причины такого
разделения и место пакетов в модели артефактов — в разделе
[Модульная структура](modules/#package-manager).

## Контракт CLI + JSON {#protocol}

Каждая команда поддерживает `--json`. Успешный ответ и ошибка возвращаются в едином конверте:

```json
{ "protocol": 1, "ok": true,  "data": { }, "errors": [] }
{ "protocol": 1, "ok": false, "data": null, "errors": [ { "code": "pm.manifest.invalid", "message": "...", "context": { } } ] }
```

- `trust-pm --version` — версия приложения и версия протокола.
- `trust-pm capabilities --json` — версия протокола, список команд и возможностей.
- Согласование возможностей выполняется по номеру протокола; при несовместимости компилятор
  сообщает об ошибке (без «тихой» деградации).

## Команды {#commands}

| Команда | Назначение |
|---|---|
| `version` | Версия и версия протокола |
| `capabilities` | Список команд и возможностей |
| `info <path>` | Описание пакета/манифеста (манифест, список записей, sha256 архива) |
| `pack <dir> [-o <out.trust>]` | Детерминированная упаковка каталога в `*.trust` |
| `resolve --manifest <file> --source <dir\|url>` | Разрешение графа зависимостей |
| `fetch` / `install` | Загрузка/установка в кэш (install дополнительно распаковывает) |
| `list --cache <dir>` | Список артефактов в кэше |

Режимы: `--offline` (без сети, обслуживание из кэша), `--frozen` (только `trust.lock.json`).

## Пакет `*.trust` {#package-format}

`*.trust` — **пакет**: архив `tar` + `zstd`, **портативный**, содержит только файлы исходного
текста `*.src` и/или вложенные пакеты `*.trust`, а также манифест и человекочитаемое описание.

- **Детерминизм**: повторная упаковка одного дерева даёт тот же архив (байт-в-байт) и тот же
  sha256 (записи отсортированы, `mtime=0`, `uid/gid=0`, фиксированные права).
- **Манифест** — отдельный файл `trust.pkg.json` в корне пакета; его наличие — признак корня
  пакета (каталог с собственным манифестом = вложенный пакет). Человекочитаемое описание —
  отдельный файл `README.md`.
- **Контроль целостности — внешний** (индекс источника, `trust.lock.json`); внутри манифеста
  хеша нет, чтобы не возникало самоссылки.

Формат `.trust` и работа с деревом исходников (границы по манифесту, вложенные пакеты,
поиск/чтение модулей, упаковка/распаковка, sha256 архива) реализованы **разделяемым
компонентом** `packages` — общим с компилятором. `trust-pm` отвечает за зависимости, решатель,
кэш, сеть/подпись и внешний контроль целостности.

Минимальный манифест:

```json
{
  "schema": 1,
  "name": "acme/foo",
  "version": "1.2.0",
  "dependencies": { "acme/bar": "^2.0" }
}
```

Версия — семантическое ядро `MAJOR.MINOR.PATCH`. Диапазоны: `*`, `=`, `>=`, `>`, `<=`, `<`,
`^`, `~`, конъюнкция через запятую (`^1.2,<1.5`).

## Кэш и офлайн {#cache}

Кэш адресуется по sha256 (`<cache>/artifacts/<sha256>`); параллельные запуски защищены файловой
блокировкой. `trust.lock.json` фиксирует разрешённый набор и хеши, поэтому `--frozen --offline`
обслуживает сборку из кэша без обращения к источнику.

## Интеграция с компилятором {#integration}

`trust` перед обработкой исходника вызывает `trust-pm resolve` (если рядом найден
`trust.pkg.json`, а режим не `off`). При отсутствии `trust-pm` выдаётся явная ошибка с
инструкцией; режим `--pm-mode=off` оставляет только локальные файлы. Флаги:
`--pm=<path>`, `--pm-mode=auto|on|off`, `--pm-manifest=<file>`, `--pm-source=<dir|url>`,
`--pm-cache=<dir>`, `--offline`, `--frozen`.

**Границы:** импорт и связывание модулей из уже скомпилированного пакета (`*.pcp`) ещё не
реализованы; `trust-pm` пока подготавливает разрешённый набор пакетов, а не подключает их к
компиляции. Формат реестра/индекса, подпись пакетов и системные каналы `.deb`/`.rpm` — отдельные
задачи.
