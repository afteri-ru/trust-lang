## Фундаментальные понятия

*TrustLang* — язык с **динамической типизацией**: явно указывать тип переменной не обязательно.
Указанный тип не влияет напрямую на размер памяти, которую занимает объект; он используется для
проверки совместимости (когда существующему объекту присваивается значение другого типа), для
проверки типа возвращаемого результата функции (если он указан) и для управления способом
размещения в памяти [нативных типов](native/).

Присваивание нового значения возможно только тогда, когда типы совместимы или допускают
автоматическое приведение. Это справедливо как на этапе компиляции, так и во время выполнения.

*TrustLang* имеет **закрытую иерархическую систему типов**: любой новый тип данных обязательно
наследует один из уже существующих. Это напоминает модель `Object` в Java и лежит в основе
[обобщённого программирования](../syntax/generics/). Полное описание иерархии — на странице
[Система типов](type_system/).

Каждый тип имеет **краткое имя** (начинается с двоеточия, например `:Int32`) и функцию-конструктор
(то же имя без двоеточия). Новый экземпляр создаётся вызовом конструктора. Типы могут быть
синонимами (одинаковое краткое имя в разных пространствах имён); в этом случае нужна явная
квалификация имени. Явное приведение выполняется вызовом типа: `:Int32(x)`,
`:Bool(value)` (см. [Преобразование типов](convert/)).
