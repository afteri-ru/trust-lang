Числовые типы — простые (скалярные) типы данных *TrustLang*. Основы типизации описаны на странице
[Система типов](type_system/), а массивы, диапазоны и (в перспективе) тензоры — в разделе
[Диапазоны, массивы и тензоры](containers/).

## Целые числа

Имена целых типов соответствуют их разрядности: `:Int8`, `:Int16`, `:Int32`, `:Int64`.
Целочисленный литерал получает минимальный знаковый тип, в который влезает его значение
(например, `5` → `:Int8`), а значение, не помещающееся в `:Int64`, становится `:BigInteger`.
Тип литерала можно задать явной аннотацией `литерал :Type` (например, `1 :Bool`, `255 :Int16`) —
при выходе за диапазон типа возникает ошибка компиляции, а не молчаливое переполнение.

Для взаимодействия с нативным C++-кодом у целых есть беззнаковые синонимы
(`:Byte`, `:Word`, `:DWord`, `:UInt16`/`:UInt32`/`:UInt64`, ...), которые применяются при вызове
[нативных функций](native/). В арифметике предпочтительны знаковые типы — так удаётся избежать
классических проблем беззнаковой арифметики (например, вычитания, дающего огромное «отрицательное»
значение).

### Логический тип {#bool}

Логический тип `:Bool` принимает только значения `0` или `1` (`false`/`true`). Он выделен в отдельную
категорию (значения `@true`/`@false` в DSL — это `1 :Bool`/`0 :Bool`) и в зависимости от операции может
вести себя как целочисленный. Явная `0 :Bool`/`1 :Bool`-аннотация создаёт именно логическое значение.

## Числа с плавающей точкой

Типы с плавающей точкой соответствуют разрядности: `:Float16`, `:Float32`, `:Float64` (синонимы
`:Single`, `:Double`). Разряды числа можно разделять знаком подчёркивания для читаемости: `10_000`.

## Рациональные числа и произвольная точность {#rational}

Для вычислений с неограниченной точностью используются **рациональные числа**: это дробь
\( \frac{m}{n} \), где числитель *m* — целое, а знаменатель *n* — натуральное (больше нуля).
В качестве разделителя дроби используется обратная косая черта: `1\1` — единица, `-55\3` — дробь
\( \frac{-55}{3} \). Арифметика рациональных чисел строится на `:BigInteger` (GMP) и не теряет точность;
смешивание с числами с плавающей точкой требует явного преобразования.
