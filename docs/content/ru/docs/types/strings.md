*TrustLang* поддерживает два типа строк:

- `:StrChar` — универсальные байтовые UTF-8 строки;
- `:StrWide` — системные (широкосимвольные) строки.

## Байтовые строки `:StrChar` {#StrChar}

Единичный элемент байтовой строки — один байт (точнее `:Int8`, восьмибитное целое со знаком). Размер
строки возвращается в байтах, а доступ по индексу обращается к байту последовательности. Так как данные
интерпретируются как последовательность UTF-8 символов, при изменении отдельных байт нужно соблюдать
осторожность.

## Системные строки `:StrWide` {#StrWide}

Единичный элемент системной строки — широкий символ `wchar_t`, а размер возвращается в широких символах.
Размер `wchar_t` зависит от операционной системы: в Windows один символ `:StrWide` занимает 2 байта,
в Linux — 4. Основное назначение системных строк — упрощение работы в текстовом терминале: один символ
всегда соответствует одному знакоместу без конвертации кодовых точек UTF-8.

Несмотря на разный единичный элемент, внутреннее представление у обоих типов одинаковое: данные строк
хранятся в виде байтовой UTF-8 последовательности.

## Форматирование строк {#format}

К любой переменной можно обратиться как к функции (указав после имени круглые скобки), создав тем самым
копию/клон объекта; для строк такой вызов используется как **шаблон форматирования** данных.

Форматирование возможно двумя способами:

- **Строка формата в стиле `printf`.** Строке формата задаётся тип `:FmtChar`/`:FmtWide`. При таком
  форматировании именованные аргументы использовать нельзя, а типы аргументов проверяются только на этапе
  компиляции. Такую форматную строку можно передать последним аргументом функции для проверки типов
  следующих аргументов.
- **Во всех остальных случаях** (любая строка по умолчанию) формат соответствует библиотеке
  [{fmt}](https://fmt.dev/latest/syntax.html): можно указывать как порядковый номер аргумента, так и его
  имя. Проверка аргументов выполняется при клонировании строки (во время компиляции и выполнения).

{{< unreleased why="именованные аргументы в форматной строке (name = …) не реализованы: работает формат с позиционными плейсхолдерами → std::format без именованных аргументов (см. playground/string_format.src)" />}}

```python
$fmt := '%s: %d' :FmtChar;  # формат как в printf
$result := $fmt('value', 123);

$template := "{0}: {1}";    # формат как в {fmt}
$result := $template('value', 123);
```
