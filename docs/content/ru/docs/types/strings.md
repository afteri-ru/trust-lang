*TrustLang* поддерживает два типа строк:

- `:StrChar` — универсальные байтовые UTF-8 строки; литерал — в двойных кавычках `"…"`;
- `:StrWide` — системные (широкосимвольные) строки; литерал — в одинарных кавычках `'…'`.

## Байтовые строки `:StrChar` {#StrChar}

Единичный элемент байтовой строки — один байт (точнее `:Int8`, восьмибитное целое со знаком). Размер
строки возвращается в байтах, а доступ по индексу обращается к байту последовательности. Так как данные
интерпретируются как последовательность UTF-8 символов, при изменении отдельных байт нужно соблюдать
осторожность.

## Системные строки `:StrWide` {#StrWide}

Единичный элемент системной строки — широкий символ `wchar_t`, а размер возвращается в широких символах.
Размер `wchar_t` зависит от операционной системы: в Windows один символ `:StrWide` занимает 2 байта,
в Linux — 4. Основное назначение системных строк — упрощение работы в текстовом терминале: один символ
всегда соответствует одному знакоместу без конвертации кодовых точек UTF-8.

Несмотря на разный единичный элемент, внутреннее представление у обоих типов одинаковое: данные строк
хранятся в виде байтовой UTF-8 последовательности.

Ширина строкового литерала задаётся кавычками: `"…"` — `:StrChar`, `'…'` — `:StrWide`.
Raw-строки следуют тому же правилу по ограничителю: `R"(…)"` — `:StrChar`, `R'(…)'` — `:StrWide`.

## Методы строк {#methods}

Строки предоставляют методы базового класса C++ (`std::string`/`std::wstring`): доступ к элементам
(`at`, `front`, `back`), размер и ёмкость (`size`, `length`, `empty`, `capacity`, `reserve`,
`shrink_to_fit`, `resize`), изменение (`clear`, `append`, `push_back`, `pop_back`, `insert`, `erase`,
`replace`, `assign`) и операции (`find`, `rfind`, `substr`, `compare`, `starts_with`, `ends_with`,
`contains`). У `StrChar` дополнительно — `c_str()` и `data()` (результат — `const char*`).

## Перебор строки и конверсия {#iterate}

Курсор по строке — единый тип-итератор `Iterator<T>` стандартной библиотеки, помеченный `@[borrowed]`
(см. [Перебор коллекций](containers/)). Метод `chars()` возвращает курсор по элементам (`:Int8` для
`StrChar`, `:Int32` для `StrWide`), построенный из `begin/end` строки; пока курсор жив, строку менять
нельзя. Конверсия между типами строк — методы `toWide()`/`toNarrow()` (UTF-8 ↔ широкие символы).

```python
s : StrChar := "hello";
it : Iterator<Int8> := s.chars();
@while( it.hasNext() ) { ch := *it; ++it; };
w : StrWide := s.toWide();
back : StrChar := w.toNarrow();
```

## Форматирование строк {#format}

К любой переменной можно обратиться как к функции (указав после имени круглые скобки), создав тем самым
копию/клон объекта; для строк такой вызов используется как **шаблон форматирования** данных.

Форматирование возможно двумя способами:

- **Строка формата в стиле `printf`** (тип `:FmtChar`/`:FmtWide`) в текущей версии **не реализована**
  — типа `:FmtChar`/`:FmtWide` нет (см. [Статус](../status/)). Для нативных функций с `printf`-строкой
  используется атрибут `@[format("printf", pos, ...)]` (проверка параметров на этапе компиляции,
  пример — [hello](/ru/playground/?file=hello)).
- **Во всех остальных случаях** (любая строка по умолчанию) формат соответствует библиотеке
  [{fmt}](https://fmt.dev/latest/syntax.html)/`std::format`: порядковый номер аргумента
  (`{0}`, `{1}`) или пустые `{}`. Проверка аргументов выполняется при клонировании строки
  (во время компиляции и выполнения). Именованные аргументы (`name = …`) **не реализованы**.

```python
$template := "{0}: {1}";    # формат как в {fmt}
$result := $template('value', 123);
```
