Тип данных *:Class* аналогичен словарю, но все его поля обязаны иметь имена
(доступ к свойствам по индексу также возможен). При создании экземпляра класса
создаётся новый тип, копирующий свойства и методы всех родителей.

В отличие от словаря, состав полей класса определяется на этапе компиляции и может
только расширяться относительно родительских типов. Класс создаётся как новый тип в
пользовательском [пространстве имён](/ru/docs/syntax/namespace/): имя типа - имя
класса, а вызов его как функции - вызов конструктора.

## Статус

Полноценное ООП (классы с наследованием и методами) находится в стадии проектирования.
Из «объектно-ориентированных» типов реализованы:

- **Перечисления** (`:Enum`);
- **Варианты** (`:Variant`);
- **Кортежи** (`:Tuple`).

Подробнее - в [Словарях и наборах (перечисления)](dicts/).
