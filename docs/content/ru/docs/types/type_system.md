## Принципы

*TrustLang* имеет **закрытую систему типов**: любой новый тип данных обязательно наследует
(расширяет) один из уже существующих. Это напоминает модель `Object` в Java и является основой
[обобщённого программирования](../syntax/generics/): код, написанный для «родительского» типа,
работает со всеми его наследниками.

Язык динамически типизирован: тип переменной можно указать явно или оставить автоматический вывод.
Указанный тип используется для проверок совместимости при присваивании, для проверки типа
возвращаемого значения функции и для управления размещением в памяти [нативных типов](native/).
Автоматическое приведение возможно только между совместимыми типами; в остальных случаях требуется
явное [преобразование типов](convert/).

## Категории типов

Типы данных разделяются на **простые** (скалярные, не расширяемые) и **составные**
(контейнерные и определяемые пользователем). Кратко по категориям (подробности — на
соответствующих страницах раздела):

| Категория | Типы | Описание на странице |
|---|---|---|
| Целые | `:Int8`…`:Int64`, беззнаковые синонимы (`:Byte`, `:Word`, `:DWord`), `:Bool` | [Числа и тензоры](numbers/) |
| Числа с плавающей точкой | `:Float16`, `:Float32`, `:Float64` | [Числа и тензоры](numbers/) |
| Произвольная точность | рациональные `m\n` и `:BigInteger` (GMP) | [Числа и тензоры](numbers/) |
| Строки | `:StrChar` (UTF-8), `:StrWide` | [Символьные строки](strings/) |
| Диапазоны и массивы | `:Range`, `:Array` (одномерный, `std::vector`) | [Диапазоны, массивы и тензоры](containers/) |
| Словари | `:Dictionary` (позиционные и именованные элементы) | [Словари и наборы](dicts/) |
| Пользовательские | перечисления `:Enum`, варианты `:Variant`, кортежи `:Tuple`, алиасы `::=` | [Словари и наборы](dicts/) |
| Нативные | импорт и предварительное объявление C/C++-типов и шаблонов | [Нативные типы](native/) |

Переменные могут хранить значение напрямую либо быть **ссылочными** (сильные/слабые ссылки,
`shared`/`weak`) — см. [Управление памятью](../syntax/memory/).

## Имена типов и конструкторы

Каждый тип имеет *краткое имя*, начинающееся с двоеточия (например, `:Int32`), и одноимённую
функцию-конструктор без двоеточия. Новый экземпляр создаётся вызовом конструктора: `x := Int32(5);`.
Типы могут быть синонимами — два типа с одинаковым кратким именем в разных пространствах имён;
в этом случае требуется явная квалификация имени при вызове конструктора (см.
[Именование объектов](../syntax/naming/)).

## Статус реализации

Из «объектно-ориентированных» возможностей в текущей версии реализованы только типы
`Enum`/`Variant`/`Tuple` и предварительное объявление нативных классов (см. [Классы](class/)).
Комплексные числа (`:Complex16/32/64`), многомерные тензоры (полноценные `:Tensor`),
ООП-классы с наследованием, корутины и чистые функции не реализованы — подробнее в
[Статусе реализации и ограничения](../status/).
