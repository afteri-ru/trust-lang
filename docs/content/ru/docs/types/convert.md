Несмотря на динамическую типизацию, если тип переменной указан явно, автоматическое приведение
типов **не** выполняется — для присваивания значения несовместимого типа требуется его явное
преобразование.

## Явное приведение вызовом типа

Явное преобразование выполняется вызовом функции с именем целевого типа (кратким именем без
двоеточия): `:Int32(x)` читается как `Int32(x)` — это вызов конструктора/приведения типа.

```python
n := Int32(3.14);      # число с плавающей точкой → целое
b := Bool(5);          # число → логическое (0/1)
f := Float64(n);       # целое → число с плавающей точкой
```

Приведение выполняется **с контролем диапазона**: если значение не помещается в целевой тип
(сужение), возникает ошибка — как на этапе компиляции для известных значений, так и в рантайме для
переменных. Молчаливого «обрезка»/переполнения нет.

## Словарь как универсальный тип

Словарь — единственный тип, который может быть приведён к любому другому: для создания значения
конкретного типа достаточно передать словарь аргументом в приведение/конструктор типа. Подробнее —
в [Словарях и наборах](dicts/).
