Функция определяется операторами [создания объектов](../operators/create/), имя функции должно
соответствовать [правилам именования](../syntax/naming/) и завершаться круглыми скобками. Телом обычной
функции служит [блок кода](../operators/#block), находящийся в пространстве имён её определения.

У аргументов и у типа возвращаемого значения можно указать один тип или сразу несколько допустимых
(перечисляются через запятую в угловых скобках):

```python
func(arg:<:Int8, :Int16, :Int32>): <:Int8, :Int16, :Int32> := { $arg * $arg };
```

*TrustLang* на уровне синтаксиса поддерживает несколько видов функций.

## Обычные функции {#func}

Обычная функция ничем не ограничена в смысле С/С++: может содержать условия, циклы, вызовы других
функций и т.д. Создаётся оператором `:=`:

```python
hello(str:StrChar) := {
    @print('call: {}\n', str);
};

@main() := {
    hello('Привет, мир!');
};
```

## Именованные и опциональные параметры {#named-params}

**Именованные параметры** позволяют передавать аргументы по имени (с префиксом «.»), а не по позиции:

```python
func(width:Int32, height:Int32) := { ... };

func(.width=640, .height=480);
func(.height=480, .width=640);  # порядок не важен
```

Имя именованного аргумента не перекрывается макросом препроцессора (см.
[Именование объектов](../syntax/naming/)).

**Опциональные параметры** имеют значение по умолчанию и могут быть опущены при вызове: имя аргумента
отделяется от значения знаком `=`. Сначала перечисляются обязательные параметры, затем — со значениями
по умолчанию. Функция, допускающая произвольное число аргументов, заканчивает список параметров
многоточием `...`.

## Чистые функции {#pure}

Чистая функция не имеет побочных эффектов: возвращает результат только по своим аргументам и не
изменяет состояние программы. Синтаксис декларации `::-` **не реализован** (см. [Статус](../status/));
к понятию чистоты относится и требование иммутабельности аргументов по ссылке (см.
[Именование объектов](../syntax/naming/)).

## Сопрограммы (coroutines) {#coro}

Сопрограмма — функция-замыкание, способная приостанавливать и возобновлять выполнение (кооперативная
многозадачность). В текущей версии **не реализовано** — см. [Статус](../status/) и раздел
[Многопоточность и асинхронность](../operators/async/).

## Анонимные функции {#anonymous}

Анонимная функция объявляется в месте использования и не получает собственного имени (уникального
идентификатора). Если анонимная функция — обычная или чистая, в качестве имени используется символ
нижнего подчёркивания `_`; для [лямбда-выражения](#lambda) имя можно не указывать.

Анонимные функции обычно используются для однократного применения в месте определения: передаются
аргументом в другую функцию (функция обратного вызова, предикат) или при реализации
[многопоточного/асинхронного программирования](../operators/async/).

## Лямбда-выражения (замыкания) {#lambda}

Лямбда-выражение объявляет анонимную функцию по месту применения и допускает *замыкание (closure)* на
лексический контекст, в котором оно использовано. Синтаксис близок к лямбда-выражениям в C++:

```cpp
[ captures ] (arguments): return-type { body };
```

Замыкание по определению не может быть чистой функцией. Лямбда-выражение можно вызвать сразу после
определения, указав круглые скобки после закрывающей фигурной: `[](){ ... }();`.

## Переопределение и перегрузка функций {#redefinition}

Поскольку *TrustLang* позволяет вызывать нативные С/С++-функции напрямую и делать
[вставки C++-кода](../operators/#block), переопределение и перегрузка функций имеют свои особенности.

- **Переопределение (overriding)** — реализация методом подкласса метода, объявленного в суперклассе
  (фундаментальный принцип ООП).
- **Перегрузка (overloading)** — создание нескольких функций с одним именем, но разным набором
  параметров; нужный вариант выбирается на этапе компиляции по параметрам.

### Переопределение (overriding) {#overriding}

Переопределение допускается не только для методов класса, но и для обычных функций (механизм, похожий
на `LD_PRELOAD`, реализованный средствами самого языка). Чтобы функцию можно было переопределить, при её
создании не должен быть указан признак иммутабельности. Если суперкласс объявил метод мутабельным
(виртуальным), а подкласс реализует его с признаком иммутабельности, это равносильно `override final`
(без дальнейшего переопределения):

```python
base::func() := { ... };   # virtual
class1::func() = { ... };  # override
class2::func^() = { ... }; # override final
```

Переопределение идёт **по имени функции** без учёта аргументов, однако новая функция должна иметь
аргументы, [совместимые](../syntax/generics/) с типом аргументов исходной функции.

### Перегрузка (overloading) {#overload}

Перегрузка возможна только для функций, объявленных как [нативные](../types/native/). У нативной функции
все типы аргументов указываются явно и являются нативными типами. Нативные функции доступны для прямого
вызова из языков С/С++:

```python
%func(arg:Int8):None := {};   # void func(int8_t)
%func(arg:Byte):None := {};   # void func(uint8_t)
%func(arg:Int64):None := {};  # void func(int64_t)
```
