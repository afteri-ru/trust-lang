Диапазоны, массивы и тензоры - контейнерные (коллекционные) типы для работы с
последовательностями и многомерными данными.

## Диапазоны (:Range)

Диапазон - специальный тип данных, приблизительный аналог «генератора» в Python.
К диапазону можно обращаться как к итератору, и он будет поочерёдно выдавать
элементы в указанном интервале с заданным шагом. Диапазон в тексте программы
указывается как два или три элемента через две точки: `1..5` - диапазон от единицы
до пяти с шагом по умолчанию 1. В качестве параметров диапазона можно указывать
не только литералы, но и имена переменных и даже рациональные числа. Например,
`0,1..$stop..0,1` - диапазон от 0,1 до значения переменной `$stop` с шагом 0,1,
или `0..1\10` - диапазон рациональных чисел от 0 до 10.

Диапазон целых чисел можно использовать в качестве индекса у объектов, допускающих
доступ по индексу (тензоры, словари, строки). Это поведение аналогично slice в
Python: `array[1:5]` в Python означает то же, что и `array[1..5]` в *TrustLang*.

```bash
$tensor[..., 0] = 0; # Обнулить первые элементы в каждом измерении.
```

## Массивы

Одномерные массивы поддерживаются литералами `[1, 2, 3,]` / `[...]:Type`
(→ `std::vector<Elem>`), конструктором `:Array(...)`, доступом по индексу `a[i]` и
методами массива (`count`, `at`, `first`, `push_back`, ...). Переменные с типом
массива могут создаваться как ссылочные, так и по значению.

## Тензоры

Тензоры - многомерные массивы (на базе LibTorch). В отличие от массивов,
переменные-тензоры всегда создаются как ссылочные, и их значение нельзя присвоить
переменной по значению. Число - элементарный тип, обрабатываемый на аппаратном
уровне, тогда как тензор нулевого размера - объект (тензор). Конвертирование числа
в тензор нулевого размера и обратно происходит автоматически, если типы совместимы.

### Индексация массивов и тензоров {#indexing}

Доступ к элементам массива или тензора происходит по целочисленному индексу,
который начинается с 0. Для многомерного тензора индексы перечисляются в квадратных
скобках через запятую.

Поддерживается доступ через отрицательный индекс (как в Python: -1 - последний
элемент, -2 - предпоследний и т.д.).

{{< unreleased why="отрицательный индекс в текущей версии НЕ работает как в Python: доступ a[-1] вызывает рантайм-исключение std::out_of_range. Диапазоны в индексе, значение :None и многоточие `...` в индексе тензора НЕ реализованы" />}}

В качестве индекса тензора могут быть использованы диапазоны (как в Python), а также
значение `:None` и многоточие `...`. `:None` означает произвольный размер тензора в
одном конкретном измерении, `...` - в любом количестве измерений (поэтому
встречается в индексе тензора только однократно).

Литерал тензора записывается в квадратных скобках с обязательной завершающей
запятой: `[1, 2,]`. После закрывающей скобки тип тензора может быть указан явно.
Если тип не указан, он выводится автоматически с выбором минимально возможного
байтового размера.
