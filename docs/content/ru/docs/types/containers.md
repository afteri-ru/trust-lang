Диапазоны, массивы и (в перспективе) тензоры — контейнерные (коллекционные) типы для работы с
последовательностями и многомерными данными.

## Диапазоны (:Range)

Диапазон — тип, приблизительный аналог «генератора» в Python: он поочерёдно выдает элементы в заданном
интервале с заданным шагом. В тексте диапазон указывается двумя или тремя элементами через две точки:
`1..5` — от единицы до пяти с шагом по умолчанию 1; шаг задаётся третьим элементом: `0..10..2`.
В качестве границ и шага можно использовать не только литералы, но и переменные, и рациональные
числа: `0.1..$stop..0.1` — от 0.1 до `$stop` с шагом 0.1; `0..100:Rational` — диапазон рациональных чисел.

## Массивы (:Array)

Одномерные массивы поддерживаются литералами `[1, 2, 3,]` (→ `std::vector<Elem>`), конструктором
`:Array(...)`, доступом по индексу `a[i]` и методами массива (`count`, `at`, `first`, `push_back`, ...).
Переменные с типом массива могут создаваться как по значению, так и как ссылочные.

Оставшиеся позиции массива можно дозаполнить оператором `... expr ...` (последним элементом) —
размер берётся из размерного типа-цели: `v:Int32[10] := [2, 3, ... 42 ...,];` (см.
[Создание значений: заполнение тензоров](../operators/create/)).

## Тензоры (:Tensor)

`:Tensor` — встроенный (предобъявленный) тип; реализация (LibTorch) поставляется провайдером
`tensor.trust` и toolchain-плагином `tensor_cpu`. Тип известен компилятору всегда, а без
возможности `with-torch` (`-DWITH_TORCH=ON`) использование провайдера даёт диагностику до линковки.

Тип задаётся элементным типом и размерностями: `:Float32[2,3]` (более одной размерности —
всегда тензор). Альтернатива — `:Tensor[2,3]` с выводом dtype из инициализатора
(аннотация элемента `1:Float32`, хвостовая `]: Float32` или типы значений). Значение можно
создать конструкцией `:Float32[2,3](1,2,3,4,5,6)` или литералом
`m :Tensor[2,3] := [1,2,3,4,5,6,]:Float32`. Одномерное `:Float32[3]` остаётся массивом.

Поддерживаются: индексация `t[i]`, `t[i,j]` (включая отрицательные индексы), срез `t[a..b..step]`,
поэлементная арифметика `+ - * /` (тензор⊗тензор с одинаковым dtype и формой, тензор⊗скаляр),
`matmul`, `sum`, `reshape`, методы `rank/size/shape/at`. Сравнения тензоров и sparse-операции
пока не реализованы (явная диагностика).

```python
m :Float32[2,2] := [1,2,3,4,];
n := m * 2;
x := n[1,-1];      # 8
```

## Индексация

Доступ к элементам массива выполняется по целочисленному индексу, начиная с 0:

```python
a := [10, 20, 30,];
x := a[0];   # 10
```

Отрицательные индексы (как в Python) **не поддерживаются**: обращение `a[-1]` вызывает рантайм-исключение.
Диапазоны в индексе (`a[1..3]`), значения `:None` и многоточие `...` в индексе также пока не реализованы.

## Перебор коллекций

Перебор элементов массива, диапазона или словаря выполняется циклом `@while(коллекция)` с
деструктуризацией текущего элемента (готовый пример — в
[песочнице](/ru/playground/?file=foreach); подробнее — [Циклы](../operators/flow/)).

Стандартная библиотека предоставляет единственный тип-итератор `Iterator<T>` — класс, помеченный
`@[borrowed]`. Он отображается на C++ `trust::Iterator<T>` — единый type-erased курсор, доступный
без явного импорта (загружается prelude; отключается `--no-stdlib`). Курсор создаётся из
Trust-объекта `Iterator(obj)` (через `begin()/end()`) либо из пары стандартных C++-итераторов
`trust::Iterator<T>(first, last)` (используется кодогенерацией, в том числе для reverse через
`rbegin()/rend()`). Интерфейс унифицирован с C++: `*it`, `++it`, `it++`, `--it`, `it--`;
завершённость проверяется через `it.%hasNext()` (C++ `explicit operator bool`). Любая переменная
типа `Iterator<T>` автоматически зависима от исходного объекта: изменение источника при живом
курсоре — диагностика `-Wborrowed` в точке мутации (см. [Контроль инвалидации производных представлений](../safety/borrowing/)).
Зависимость снимается `it = _;` или привязкой к другому источнику.
Атрибут наследуется производными типами (`Iterator<Int32>` и др.).
