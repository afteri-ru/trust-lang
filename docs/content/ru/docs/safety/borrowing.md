Контроль инвалидации ссылок (атрибут `@[borrowed]`, диагностика `-Wborrowed`) защищает от
**висячих ссылок** (`dangling`): ссылка/указатель, полученные из данных объекта, становятся
недействительными, когда эти данные меняются. *TrustLang* отслеживает такие «зависимые»
переменные и сообщает об их использовании **после мутации источника** — на этапе компиляции, а не
во время выполнения.

## Модель

- **Источник** (main variable) — объект, из данных которого получена зависимая ссылка.
- **Зависимая** — переменная, указывающая в данные источника.
- **Инвалидация**: мутация данных источника делает ранее полученный **view в эти данные**
  недействительным (dangling). Использование такой зависимой после мутации — диагностика
  `-Wborrowed=ignore|warning|error`.
- **Копирование атрибута**: переменная, инициализированная или присвоенная из зависимой, тоже
  становится зависимой от того же корневого источника; переприсваивание независимым значением
  снимает зависимость (release).

> **Разграничение (важно).**
> - **Инвалидация / borrowed** — про **view в данные**: внутреннее поле/буфер, возвращённые
>   методом-контрактом `@[borrowed]`. Мутация источника делает такой view висячим. (Индекс `obj[i]`
>   сюда НЕ входит — это копия значения.)
> - **Время жизни (refcount)** — `shared`/`weak`: слабый наблюдатель истекает, когда освобождён
>   последний владелец. Это **не инвалидация**, а штатное поведение счётчика ссылок.
> - **Нарушение заимствования (borrow)** — мутация владельца/данных при **живом заёме** (borrow):
>   эксклюзивный доступ нельзя совмещать с мутацией (aliasing XOR mutability). Диагностирует
>   borrow-checker (`-Wborrow-*`), а **не** borrowed.

## Что отслеживается

Borrowed отслеживает только сущности с явным контрактом `@[borrowed]`:

- **класс/тип**, помеченный `@[borrowed]` (по контракту держит view/указатель на чужие данные —
  любая переменная такого типа зависимая). Атрибут **наследуется производными типами**
  (специализации/алиасы, напр. `Iterator<T>`); отдельная пометка методов не требуется;
- **метод**, помеченный `@[borrowed]` (возвращает view во внутренние данные — результат зависим
  от объекта);
- **переменная**, помеченная `@[borrowed]` (явно объявляет переменную зависимой).

Авто-трекинга по форме выражения НЕТ: значение-копии (в т.ч. `obj[i]` — **копия** элемента) и умные
ссылки (`shared`/`weak`/`unique`) не являются зависимыми. Для умных ссылок мутация владельца при
живом заёме — это нарушение заимствования (borrow-checker, `-Wborrow-owner-mutated`).

## Пример

Контракт `@[borrowed]` можно повесить на переменную (явная зависимость), на класс/тип (все
переменные типа зависимы) или на метод (его результат зависим от объекта):

```trust
a := [1, 2, 3,];
@[borrowed@] w := a;        # w зависим от a
a = [4, 5, 6,];             # ОШИБКА -Wborrowed: изменение источника при живом заёме
```

Снятие зависимости — переприсваиванием независимым значением:

```trust
a := [1, 2, 3,];
b := [9, 9, 9,];
@[borrowed@] w := a;
w = b;                      # заём снят
a = [4, 5, 6,];             # OK
```

> **Статус.** Заём `&` определён только для `shared` (→ weak-наблюдатель); у монопольного `unique`
> заём ЗАПРЕЩЁН (`& u` → ошибка; допустимы только move/swap). Зависимости данных (view-объекты вроде
> итераторов/span) отслеживает атрибут `@[borrowed]` (severity `-Wborrowed=`, снятие — переприсваиванием).

Тесты: `test/lit/.../borrowed/value_copy_not_tracked.src` (значение-копия не отслеживается);
borrow-диагностики — `test/lit/.../borrow/*`.
