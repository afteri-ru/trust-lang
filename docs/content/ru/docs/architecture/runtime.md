## Библиотека времени выполнения

Типы, опирающиеся на рантайм (например, `Rational`), требуют библиотеку
**trust-runtime**, которая собирается и как динамическая (`trust-runtime.so`), и как
статическая (`trust-runtime.a`). При компиляции исполняемого файла конвейер линкует
рантайм в соответствии с `--link-runtime` (по умолчанию `static`). См.
[Компилятор (CLI)](../tooling/cli/).

Публичные заголовки рантайма и исходники stdlib не копируются отдельно: их
содержимое встроено в библиотеки рантайма / компилятор и остаётся синхронизированным
с ними по версии.

## Встроенные типы

Встроенные типы данных (числа, строки, словари, классы, функции, итераторы,
нативные типы, преобразования) описаны в разделе [Типы данных](../types/).

Ключевые встроенные типы, требующие рантайма:

- **`Rational`** - рациональные числа неограниченной точности (на базе GMP).
- **Тензоры** - многомерные массивы на базе LibTorch (`std::vector<Elem>` для
  одномерных; многомерные зарезервированы для LibTorch-бэкенда).

## Интринсики рантайма

Рантайм предоставляет интринсики, к которым сводятся языковые конструкции,
например `trust::intrinsic_assert` (проверка утверждений) и `trust::trust__abort__`
(аварийный выход с диагностикой и backtrace).
