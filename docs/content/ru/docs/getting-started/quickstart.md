TrustLang - высокоуровневый язык общего назначения, реализованный как транспилятор
в код C++. Ниже - минимальный пример и способы запуска.

## Пример «Hello, world!»

```trust
hello(str:StrChar) := {
    @print('call: {}\n', str);
    str;
};

@main() := {
    hello('Привет, мир!');
};
```

Вывод:

```
call: Привет, мир!
Привет, мир!
```

## Пример с рациональным числом и циклом

Базовые типы данных, включая рациональные числа неограниченной точности, доступны
«из коробки» и поддерживаются синтаксисом:

```trust
#!../_build/trust --run

@main() := {
    $fact := 1\1;  # рациональное число 1 (без ограничения точности)
    $mult := 1;

    @while( mult <= 40 ) {
        fact *= mult;
        mult += 1;
    };

    @print('{}', fact);   # результат факториала 40
};
```

Вывод:

```
815915283247897734345611269596115894272000000000\1
```

## Запуск компилятора

Сборка и запуск тестов:

```sh
cmake -B _build && cmake --build _build
ctest --test-dir _build --output-on-failure   # все тесты
```

Компилятор `trust` транслирует `.src`-файл в код C++ (`.cppt`) и собирает
исполняемый файл через внешний C++ компилятор (по умолчанию `clang++`).
Полный список опций - в разделе [Инструменты](../tooling/).
