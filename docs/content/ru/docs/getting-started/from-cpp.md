*TrustLang* разработан как «надстройка» над C++: сохраняет его возможности, но
убирает сложную лексику, адресную арифметику и ручное управление памятью.
Проект реализован как транспилятор в C++, поэтому весь существующий C/C++ код и
библиотеки остаются доступными.

## Ключевые отличия от C++

- **Управление памятью** - автоматическое, без сборщика мусора: RAII и сильные/слабые
  ссылки; ручное `new`/`delete` не требуется.
- **Синтаксис** - основан на грамматических правилах (без ключевых слов); привычная
  запись доступна через DSL-макросы (`@if`, `@while`, `@func`, ...).
- **Типизация** - статическая и динамическая, с явным указанием типов при желании.
- **Встроенные типы** - рациональные числа, массивы, диапазоны, тензоры (LibTorch).
- **Безопасность** - ошибки управления памятью и гонки данных обнаруживаются на этапе
  компиляции; проверка контрактов (Z3).

## Прямая работа с C/C++

Взаимодействие с C++ - без FFI-обвязок:

```trust
@extern sqrt(x:Float64):Float64        # вызов нативной функции
@forward open(path:StrChar, flags:Int32):Int32

{% for (int i = 0; i < 10; ++i) { printf("%d\n", i); } %}   # вставка C++ кода
```

Подробнее - в [Взаимодействии с C/C++](../syntax/cpp-interop/).

## Сборка

Компилятор `trust` транслирует `.src` в C++ (`.cppt`) и собирает исполняемый файл
внешним C++ компилятором (по умолчанию `clang++`).
