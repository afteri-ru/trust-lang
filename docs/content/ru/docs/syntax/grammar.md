Грамматика *TrustLang* определяется генераторами лексера и парсера (Flex/Bison) и
является источником истины для синтаксиса. Исходники:

- лексер - `src/syntax/lexer.l`;
- парсер - `src/syntax/parser.y.in` (генерируется в `parser.y` / `parser.tab.cpp`).

Полная формальная грамматика (BNF) генерируется из `parser.y.in` на этапе сборки.

## Ключевые синтаксические правила

- Операторы разделяются точкой с запятой `;`.
- Блоки кода - фигурные скобки `{ ... }`.
- Синтаксис основан на грамматических правилах (не на ключевых словах); привычная
  запись достигается через [DSL-макросы](dsl/).
- Термины распознаются лексером и обрабатываются макропроцессором до парсинга.
