*TrustLang* глубоко интегрирован с экосистемой C/C++: прямые вызовы функций,
встраивание C++-кода, использование стандартной библиотеки и вызовы функций
*TrustLang* из C++.

Готовые, запускаемые примеры — в песочнице: [нативные функции](/ru/playground/?file=native_functions),
[нативная линковка](/ru/playground/?file=native_link).

## Импорт нативных функций: `@extern` / `@forward`

Мнемонические команды связывают trust-имя с нативным C/C++-символом:

```trust
@extern abs(x:Int32):Int32   # abs(x:Int32):Int32 := %abs ...
@forward open(path:StrChar, flags:Int32):Int32
```

- `@extern` - импорт по нативному имени (trust-имя = нативное имя без префикса `%`).
- `@forward` - предварительное объявление (имя указывается первым, тело - многоточие).

Сырая запись: `%name(...):T := ...;` (forward-декларация) и
`name(...):T := %native...;` (импорт-алиас).

## Встраивание C++ кода: блоки `{% ... %}`

```trust
{% for (int i = 0; i < 10; ++i) { printf("%d\n", i); } %}
```

Нативный синтаксис вставляется в выходной C++ код напрямую.

## Атрибуты нативных деклараций

- `@[link("имя")]` - добавить `-l<имя>` к линковке.
- `@[include("header")]` - подключить заголовок C++ для нативной декларации/типа. Голое имя
  (`@[include("vector")@]`) → угловой инклуд `#include <vector>`; аргумент с ведущим `"`/`<` →
  директива как есть (`#include "my/header.h"` / `#include <cstdlib>`). Заголовок эмитится в
  сгенерированный C++ только вместе с объявлением (не глобально). Мнемоника `@include("name")`
  (без `;`, перед объявлением) раскрывается в этот атрибут.
- `@[libstd]` - линковать со стандартной библиотекой.
- `@[format("printf", ...)]` - проверка аргументов против printf-строки формата.

Пример подключения заголовка нативной функции:

```trust
@include("cstdlib")
%abort(x:Int32):Void := ...;   # → #include <cstdlib> + extern "C" void abort(int32_t);
```

## Линковка

Линковка нативной декларации зависит от наличия `::` в нативном имени: без `::`
(`%sqrt`) - `extern "C"` (C-символ libc/libm); с `::` (`%std::sqrt`) - C++-линковка
без `extern "C"`. Подробнее о генерации C++ — в [Архитектуре](../architecture/).

## Нативные шаблоны-типы и шаблон-классы

C++-шаблоны-типы и нативные классы/шаблон-классы используются в TrustLang через объявления с типовыми параметрами и forward-интерфейсом (`<T> %std::vector() := ...;`, `String ::= %std::string { ... };`, `<T1,T2> Pair ::= %std::pair<T1,T2> { ... };`), а C++-заголовки подключаются on-use. Подробный синтаксис и правила — в [Нативных типах](../types/native/) и [Generics](generics/).
