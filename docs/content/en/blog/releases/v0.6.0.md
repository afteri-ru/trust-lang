## About version 0.6.0

Version 0.6.0 is a formalization stage: the language syntax and core algorithmic constructs are
fixed, along with basic types and safety checks. It is also a prototype of the transpiler
architecture and tooling (compiler, language server, debugger) plus a browser playground for
running examples. This is a proof of concept rather than a stable release: full alignment of the
content with the implementation comes in the next version.
