## New features and changes in the NewLang syntax
- Reworked the definition of object types using the [prefix naming (sigil)](/en/docs/syntax/naming/)
- Interrupting the execution flow and returning can now be done for [named code blocks](/en/docs/operators/throw/).
- Simplified the syntax for importing [native variables and functions (C/C++)](/en/docs/types/native/)
- Stabilized the syntax for [initializing with initial data](/en/docs/operators/create/#comprehensions) the values of tensors, dictionaries and arguments in function calls.
- Added built-in macros for writing code using keywords in a [DSL](/en/docs/syntax/macros/) style

## New compiler features (nlc)
- The macro processor has been completely redesigned.
- Reworked the compiler architecture with division into parser, macro processor, syntax analyzer, interpreter and code generator.

## Miscellaneous
- The documentation [website](/en/) has been ported to [Hugo](https://gohugo.io/) and made bilingual.
- Instead of binary builds, the section [Playground and example code](/en/playground/) has been added to the site for small experiments.
- Migrated to clang-16 (the transition to clang-17 and newer is planned after the full implementation of coroutines and support for extended floating-point formats).
- The number of project contributors has become more than one!
