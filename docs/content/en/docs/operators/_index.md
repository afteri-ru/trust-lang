In *TrustLang* **any construct is an expression** and returns a value, so it can be
nested inside other expressions. Statements are separated by a semicolon `;`; a group of statements
is enclosed in a code block `{ ... }`. The basic rules of blocks and expressions are described in
[Syntax](../syntax/).

Handling of emergencies and guarantees of resource release are related to the
[Memory](../safety/memory/) model, and typing operators — to the [Type system](../types/type_system/).
