## Architecture

Каталог публичного сайта (Hugo + Docsy); первоисточник — `docs/content/ru`, `content/en` — синхронный
перевод. Единая генерация — `docs/site_build.sh` (фрагменты песочницы из `examples/*.src` через
`trust-lsp --html`, затем `hugo`). Технические детали сборки — `docs/README.md`.

Публикуется только публичная документация; рабочие/промежуточные материалы — в `MEMORY.md` компонентов и
бэклоге; материалы разработки в `docs/content` не публикуются.

## Facts and invariants

- **Правило «одно место» (обязательное):** каждая возможность описана в ОДНОЙ канонической странице; в
  остальных — выжимка + ссылка. Дублирование правила/примера/таблицы — баг.
- **Код-примеры >2–3 строк не дублируются:** выжимка + ссылка в песочницу на `examples/*.src`; если фича есть,
  а примера нет — пример добавляется в `examples/`.
- **Страницы описывают ТОЛЬКО реализованный синтаксис;** статус/границы — только в `status.md`. Баннеры
  `{{< unreleased >}}` внутри страниц НЕ используются; допустим только layout-баннер уровня сайта (`dev-notice.html`).
- **Полные перечни CLI-опций/диагностик не дублируются:** источник — `trust --help`, `-Whelp`, LSP-ховеры.
- **Архитектура — один стабильный файл** (`architecture.md`), только стабильные факты; детали реализации в
  docs НЕ документируются (их источник — код).
- Актуальная версия в текстах — из `VERSION`; «0.6.x»-расхождения — ошибка.

## Decisions

- **`*_index.md` — краткая навигация + общие для раздела факты**; фундаментальное понятие — ссылкой.
- **Канонические страницы-источники:** память — `safety/memory.md`; защита стека — `safety/stack_check.md`;
  инвалидация (`@[borrowed]`, `-Wborrow-*`) — `safety/borrowing.md` (НЕ модель Rust); макросы — `syntax/macros.md`;
  типы — `types/_index.md`; C/C++ — `types/native.md`; файлы/группы/пакеты — `syntax/hierarchy.md`;
  верификация — `safety/verification.md`; инструменты — `sandbox.md`; статус — `status.md`.
- **Нет категории «итераторы»:** перебор — цикл с деструктуризацией элемента.
- **Сравнение с аналогами — только в блоге** (`blog/comparison/`, `blog/language-design/`).
- Раздел «Архитектура» — appendix для разработчиков; карта возможностей — `docs/_index.md`.
